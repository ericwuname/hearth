# hearth TUI 使用说明

## 一、启动（30 秒）

在你的 **IDE 终端**（已连到 `.133`）里：

```bash
ssh wutao@192.168.220.133          # 密码 123456
cd ~/想让它工作的目录               # ← 重要：TUI 就在这个目录里干活
hearth-tui                         # 启动（已装成系统命令，任何目录可用）
```

不想记命令的话，直接：

```bash
cd ~ && hearth-tui
```

## 二、界面四块

```
┌ hearth TUI ──────────────────────────┐   ← 顶栏（标题/版权）
├ conversation ────────────────────────┤   ← 对话区：你问 → hearth 答
│> you: 我叫小明                       │
│  hearth: 记住了                      │
│  · 🔒 landlock+seccomp (session …)   │   ← 「·」行 = 它的执行过程（沙箱/审批/工具）
│  · ───── 结果 ─────                  │
│  hearth: 好的                        │
├ input (Up/Down=history …) ───────────┤   ← 输入框
│> 输入内容 ▍                          │
├ 状态栏 ──────────────────────────────┤
│ model: agnes-3.0-flash | session: 4986ae12 | steps: 2 │
│ [fold:off hist:2 scroll:0/50] done (2s)               │
└──────────────────────────────────────┘
```

## 三、按键（输入框上方也有提示）

| 键 | 作用 |
|---|---|
| **Enter** | 发送（**第一问 = 新会话；之后自动续同一会话**） |
| **Ctrl+Q** | 退出（`q` 在空输入时也行） |
| **Esc** | 清空输入 |
| **Backspace** | 删一个字 |
| **↑ / ↓** | 翻历史输入 |
| **PageUp / PageDown** | 滚动对话区（状态栏显示 `scroll:A/B`） |
| **Ctrl+T** | **折叠/展开过程行**（`·` 那堆太吵时按它，答案会保留） |

## 四、四个典型用法

1. **问一句**
   `> 用三句话说明 hearth 是什么` → Enter

2. **让它干活**（它会写文件、跑命令、自己验证）
   ```bash
   cd ~/mywork && hearth-tui
   ```
   `> 统计 app.log 里 ERROR 有多少条、按模块分布，写成 report.md`

3. **连续对话（同一会话，它记得住）**
   `> 我叫小明，请记住` → Enter → 等结果 → `> 我叫什么名字？` → 它会答"小明"

4. **嫌过程行太吵**
   按 **Ctrl+T** → 只留你的问题和答案；再按一次恢复

## 五、四件要知道的事

1. **每次 Enter 都是真实模型调用**——等 5–60 秒是正常的（状态栏从 `running` 变 `done (Ns)`）。
2. **它在"你启动 TUI 的那个目录"里干活**（相对路径都相对那儿）。要它改哪个项目，就先 `cd` 到那儿再启动。
3. **它背后是 hearth**（Rust 引擎）——所以你看到的 `·` 行是 hearth 的沙箱、审批、工具执行过程，不是装饰。
4. **会话自动续**：状态栏那个 `session: 前8位` 就是当前会话；你说"继续"它能接着上文（已验证"记名字"测试通过）。

## 六、出问题怎么办

| 现象 | 处理 |
|---|---|
| 界面没出来 | 确认终端窗口至少 30 行高（TUI 要空间）；`echo $TERM` 应有值 |
| 发了消息一直不返回 | 状态栏看是否有 `running`；超过 2 分钟可按 `Ctrl+Q` 退出重来 |
| 界面乱码 | 终端编码设为 UTF-8 |
| 想让它换个目录干活 | `Ctrl+Q` 退出 → `cd 新目录` → 再 `hearth-tui` |
