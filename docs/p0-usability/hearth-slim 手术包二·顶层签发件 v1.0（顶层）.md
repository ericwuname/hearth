## 一、七卡签发（三确认项落笔）

1. **计划书签发** ✅——范围 S7/S8/S12/S9/S10/S11/S13 七卡，顺序照实施版（S7→S8→S12→S9→S10→S11→S13），1-2 工作日，成本=免费通道。每卡先红后绿+独立 commit+执行窗对照判据验收+问题卡制度；红线沿用（沙箱语义零触碰/tally 9 处原位）；测试构建一律 .133 Linux。
2. **S2+S9 风险备案落字** ✅——出网默认放开+三通道 key 集中 config（权限 600+不入 git）。**附加要求**：三通道 key 写入 config 时从用户记忆取用（授权在案），**key 永不入 git**——Push Protection 已实证拦过 2 处 GCP key，此关保持开启，任何 key 入库即翻车。
3. **S12 判别实验责任裁定程序确认** ✅——同一魂斗罗任务卡原版 vs 质量版重跑，用户评分对比：评分提升=提示词/自检杠杆实锤；仍 10 分=LLM 上限实锤。**结果呈顶层做责任裁定，用户终评是唯一判分**。

**七卡设计审查通过**，两处点名表扬：S8 统一暂停语义（fatal/预算/窗口/Ctrl-C 全部=落盘+投影，"不再有不可恢复的 failed"）是韧性设计的关键一跃；S12 把 Done 语义从"LLM 自报+产物非空"升级为"把任务交出来"+诚实交付条款（不许静默交半成品）——直击 RC1 家族根因。

## 二、对标补充分析（用户指令：还有没有补充的）

顶层对标 codex CLI / Claude Code 基本功全集逐项盘点，**结论：无第八卡，但有 4 项挂账+2 项路由+1 项教训**：

### 2.1 已有确认（立卡前先盘家底——本次教训）

- **精确编辑四件套已在注册表**：edit/patch/glob/grep（lib.rs:129-134 实测）——执行窗对标清单未盘存此层。**教训入库：立新卡前先 grep 家底，"不信清单信源码"**（对照案：宪法注入曾当资产、编辑工具曾当缺口，两个方向都错过）。
- **待核对一项（并入 S13 验收）**：工具**存在 ≠ 模型会用**——S13 落刀时顺带核对 edit/patch/glob/grep/tool 描述是否满足 R5-9 五要素标准，缺则同 commit 补齐（零成本顺带）。

### 2.2 真缺——挂账第二批（S15-S18，本批验收后按吴涛抽查反馈定优先级）

| # | 缺口 | 实锚 | 量级 |
|---|---|---|---|
| S15 | **bash 状态持久化（cwd/env 跨调用）** | bash.rs 无 current_dir 持久逻辑（本地实测）；Claude Code 为持久——多步构建每次重敲路径 | 小卡，实用 |
| S16 | **todo 投影接线** | todo.rs 存在但注册/接线状态待核；S5 拆相位机后长任务自组织靠模型自觉——轻量 todo 投影（纯投影不改状态机）补上 | 小卡 |
| S17 | **用量投影（/cost + /context）** | repl 内查 token/预算/上下文占用——注意力税可见化，S3+S4 瘦身效果的日常仪表盘 | 投影层小卡 |
| S18 | **headless 单轮（hearth -p）** | 脚本/CI 用；EMBER M0 产出直接抄回，联动登记 | 微卡 |

### 2.3 路由 cognition 线（不进手术包，防范围扩散）

- **MCP 客户端支持**——cognition MVP（1+1>2 的第二个 1=MCP server 集合+指令注入）的正主，本批不碰；
- **自定义斜杠命令/技能注入**——同上，cognition 线。

### 2.4 挂账观察（不立卡）

- 多模态输入（依赖 agnes-2.5-flash 图输入能力，未验证）；子代理（进阶非基本功）；git 斜杠命令（bash 可代）。

## 三、附加条款三条（并入实施版）

1. **降级链数据同尺纪律**：S9 落地后，凡经降级链（非主通道）完成的跑批轮次，数据在基准对照中**必须标注通道**（换 provider=换模型层→不可比，环境纪律既有条款）——防降级数据污染同尺对照。
2. **S8 断点文件也入安全清单**：runs/<run-id>.json 可能含用户代码/上下文——私有内容处理纪律与 sessions 同规（public 化审查时一并过）。
3. **S12 自检依赖最小化**：无头浏览器自检复用 bench/exam 既有 playwright 模式，**不新引重型依赖**；代码类自检只用工具链既有命令（node --check/py_compile/cargo check）。
