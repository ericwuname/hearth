## 四、技术决策（执行窗裁量项，顶层可否决）

1. **语言：Python 起步**——单循环几百行可完整实现，Agnes 写 Python 熟练度最高；M4 后如需性能再议 Rust；
2. **模型：agnes-3.0-flash 全程**（用户指定）；按评估报告五条硬约束实现：`enable_thinking=true` 常开、`max_tokens=65536`、仅 Chat Completions 协议、重试+超时必备（从第一天就带工具超时——hearth 的教训）、provider 配置独立可换；
3. **prompt 基底 ≤2K**：EMBER 是新路线"无治理注入"哲学的第一个实体——没有宪法注入、没有账本、没有相位机；
4. **开发环境**：.133（跑批后空闲）或 .131；MSVC/GNU 工具链问题不影响（Python）。
