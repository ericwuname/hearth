## 唯一任务项（P1）N6：任务总结分隔线不该带 `· ` 弹点

**RED 基线（评审窗 06:40:55 实测抓屏，100x24，可复现）**：

```
│· ═══════════ 任务总结 ═══════════
│· 【一句话】成功计算并回答了数字 7。
```

问题：分隔线 `═══` 被当成普通 Proc 行加了 `· ` 弹点，外观毛糙。

**锚点**：`src/main.rs` 的 `Kind::Proc =>` 分支（评测时在 :512 起，**行号可能因你的编辑漂移，一律以代码内容为准**），当前内容为：

```rust
            Kind::Proc => {
                // Fix 1: keep "· " prefix, dark gray
                let lines_iter = text.lines();
                for (i, ln) in lines_iter.enumerate() {
                    if i == 0 {
                        convo_lines.push(Line::from(vec![
                            Span::styled("· ", Style::default().fg(C_STRUCT)),
                            Span::styled(ln, Style::default().fg(C_STRUCT)),
                        ]));
                    } else {
                        convo_lines.push(Line::from(Span::styled(ln, Style::default().fg(C_STRUCT))));
                    }
                }
            }
```

**唯一改动**：把 `if i == 0 {` 这一行替换为下面新增的 `═══` 专项分支 + 原有 `else if i == 0 {`；
两个原有分支的**代码体原样保留、一字不改**：

```rust
                    if ln.starts_with('\u{2550}') {
                        // N6: section rule lines (═══) get no "· " bullet; indent like answer lines
                        convo_lines.push(Line::from(Span::styled(
                            format!("  {ln}"),
                            Style::default().fg(C_STRUCT),
                        )));
                    } else if i == 0 {
                        /* 原文不动 */
                    } else {
                        /* 原文不动 */
                    }
```

**不要做**：不要改分类逻辑（`is_summary_delim` / `is_proc` / `in_summary_block`）；不要改折叠判定；
不要改 Answer / User / Warn 分支；不要动 wrap / scroll / 状态栏。
