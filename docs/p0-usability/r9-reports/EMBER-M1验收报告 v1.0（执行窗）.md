## 四、.133 环境修复清单（部署文档应吸收）

1. `/etc/gai.conf` 加 `precedence ::ffff:0:0/96 100`（IPv4 优先）
2. `/etc/hosts` 钉 `api.agnes-ai.cn` → IPv4
3. `.bashrc` 的 `APIHUB_AGNES_AI_API_KEY` 更新为有效 key（旧 key 已失效）
4. hearth 单卡施工建议 `HEARTH_TASK_TIMEOUT_SECS=3600`（默认 900s 不足以扛 provider 抖动）
5. **改动网络配置后必须重启 hearth 进程**（DNS 缓存/连接池）
