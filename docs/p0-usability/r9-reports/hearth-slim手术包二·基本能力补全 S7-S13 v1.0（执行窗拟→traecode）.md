## S8 · run 级断点续跑（韧性核心）

消息循环每步落盘 run 状态（对话历史+scratch+产物清单+预算位——复用存量 sessions/spill 机制接入 chat 单 run）。**一切 fatal/暂停统一为"暂停"语义**：投影"断点已存（run-id），修复 X 后 `hearth resume <run-id>` 继续"——key 失效/崩溃/VM 重启/Ctrl-C 全覆盖。
**过关（先红后绿）**：任务中途 `kill -9` 进程 → `hearth resume <run-id>` → 从断点续跑到交付。

## S9 · provider 降级链

config 化降级序列：`[agnes → zhipu → gemini]`（用户三通道皆有 key）。主通道 transient 窗口耗尽或 fatal → 自动切下一通道（投影 `[fallback] 切换 provider: agnes → zhipu`）→ 全链耗尽才暂停。**免费通道分账**：各 provider 用量独立计数。
**过关**：mock 主通道 401 → 自动切 zhipu 完成任务；配置文件可增删通道。

## S10 · 流式输出

chat/repl 全模式 token 流式（SSE→终端打字机）。用户等待期可见模型在想什么/写什么——黑盒等待是信任杀手。
**过关**：真机 repl 回答逐字呈现。

## S11 · 中断保留上下文

repl 中 ESC/Ctrl-C = 打断当前模型调用（保留全部上下文），可追问/改指令续跑；连续 Ctrl-C 才退出。当前实现 Ctrl-C 直接杀。
**过关**：任务中 ESC → 立即停 → 追问"刚才做到哪" → 上下文完整可续。

## S12 · 交付前质量自检（完成语义升级——"把任务交出来"机制化）

**根因**：Done = LLM 自报+产物非空 → 10 分样子货合法交付。升级：交付前强制**产物类型化自检**——
- 代码类：编译/语法通过 + 自测执行 + （可交互产物）运行验证；
- 网页/游戏类：无 JS 错误 + 核心交互冒烟（无头浏览器点击/按键）；
- 文档类：重读一遍完整性；
自检失败 → 自动修复迭代（最多 2 轮）→ 仍不过 → 诚实投影"交付了 X，自检未过 Y，需要人工"。
**过关**：同一魂斗罗任务卡重跑——产物经自检迭代后用户评分显著提升（10 分 → 判别实验基线）。

## S13 · 内置联网搜索工具

`web_search(query)` 一等公民工具（接免费搜索源，bash curl 升级），出网策略按 S2 默认放开。做项目查资料不再依赖模型记忆。
**过关**：真机任务中模型自主调用 web_search 查资料并引用。
