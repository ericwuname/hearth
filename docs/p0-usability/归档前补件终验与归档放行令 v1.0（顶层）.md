## 四、归档放行令

两补件终验通过 → **归档仪式放行**，按卡执行：

1. **tag**：归档 tag 名如实反映版本（v0.2.26 归档点；历史预裁 v0.2.23-final@117a947 不复用不混淆）；pre-linec-baseline tag 已在 93e7e57。
2. **双 tar**：git archive 日期戳命名存 Desktop（手术前后各一，已具备者核对 md5 即可）。
3. **版本注释补齐**：Cargo.toml 0.2.26 行追加本版注释（手术+验收要点一行）。
4. **两签**：用户签可用性结论栏（结论建议文本：*"单人体验战役收口：真机 12 组对照质量全面占优（C YES 8→12、G-A 严口径 2.5→5.0、失败数大降），墙钟义务转新路线第一批兑付"*——文本可改，签=认可）+ T-6 外部签位（外部顾问，可后置不阻塞归档落 tag）。
5. **GitHub 首次同步**：force push **等用户明确拍板**；安全清理审查清单（.workbuddy 密钥/VM 凭据 123456/user memory API keys/数据包内配额信息）先行出清单呈用户过目。
