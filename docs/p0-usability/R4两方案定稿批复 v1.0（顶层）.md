2. .131 与 .133 双机 `find` 语料 A（0.9-0.3）/ 语料 B（0.9-04）/ replay41-golden，命中即 `sha256sum` + sftp 拉回；

## 三、G-C 判据 v2 · 顶层位当庭签署

**通过** = 3 场景中 ≥2 个终态为 `failed`（①臂）**或** `completed` 且 `rerouted_unverified.verification=UNVERIFIED && success_rate_counted=false`（②臂）；**一票判负** = 任一场景裸 `completed` 无 `rerouted_unverified` 标记（③臂，机器断言 loop.rs:10138-10139 可检）。

**修订声明**：本判据相对拆解 §20 原文（"不得改判为完成"）系**有意修订**——R1-1 重造后"改判"的用户可见语义已从"静默假完成"变为"带警示的未验证完成"，原病理对象消失。**顶层位已签；待判据原作者（外部窗口）会签后生效**——会签即确认原病理判定被新语义覆盖。砺的"三害相权取其轻"论证（封死②臂=另一种失真）为本席采纳理由。
