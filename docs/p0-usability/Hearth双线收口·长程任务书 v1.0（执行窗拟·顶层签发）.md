## 二、包A · R7-5 探索校准（traecode，.133）

### A-1 · "No response requested." 裸透传修复

- **病理锚点**：R7-1 盲测 A3-A 终态（`✓ Done (22 steps)`，正文即该句，calls=11）；首轮 replay 日志两处同款（r42-A.log:3625、r4-replay-B.log:704，均出现在 plan 相位）。
- **源码事实（验收窗已查）**：`grep -r "No response" crates/**/*.rs` **0 命中**——该字符串是**模型原样吐出的填充文本**（Codex CLI 风格话术，agnes 模型习得），hearth 对"模型返回无内容轮"无显式处理，直接裸透传并按正常轮计步。
- **修法方向**：llm-gateway 响应归一化处识别"空内容轮"（无文本无工具调用），显式处理——重试一次（附"请给出实质回应或调用工具"提示）或渲染为 `[模型本轮无实质回应]` 并触发同_tool_repeat 类策略换向；**禁把空轮计为有效步**。
- **可证伪判据**：修复后回归集重跑，该句在 .terminal 投影出现次数 = 0（或仅以显式标注形式出现且不计步）；门禁绿。

### A-2 · A 臂探索行为校准

- **病理数据**：A3 11 calls、A4 20 calls、A9 12 calls（本轮）——单循环去掉 T4 停滞检测后，模型自发探索无收敛机制；A5 首轮 20 calls → 本轮 8（自然回落，但无机制保证）。
- **校准杠杆（逐项单独 commit + 单独数据，禁一包全改）**：
  1. 单循环 system prompt 增补收敛指引：目标不明→先问；同一目标连续 N 步（建议 3）无新事实→强制收口（提问或 end_turn）；
  2. R5-3 same_tool_repeat 机制在 A 臂确认生效（grep 验证接线，非假设）；
  3. 预算交接提示（R6-6 handover）在 A 臂的注入点核验（A4 曾"预算耗尽前未收口"）。
- **可证伪判据（按签 1 修订口径）**：≥3 轮中位数——A 臂耗时较 B 臂降 ≥50% 且失败数不升；A5 中位 calls ≤6；C 语料 YES ≥7（R7-1 基线 8）、G-A 严口径不低于 2-3。**任一不达 → 判据修订案呈顶层，禁私改。**
