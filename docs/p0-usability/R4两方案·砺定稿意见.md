## 二、🟠 增量二：G-C 判据修订**必须显式化**——外部意见只走了一半

### 2.1 三方现在各执什么

| 方 | G-C 立场 |
|---|---|
| 拆解一 §20 原判据（判据原作者=外部窗口） | "**不得改判为完成**"；判负 = "3 个全改判" |
| 顶层终审 §一.3 | "G-C 按 A-4 方案 (a) **维持原判据**" |
| R1-1 施工实现（loop.rs:2192-2240） | 改判**仍存在**，但三重约束：产物存活重验（失效即拒绝改判→failed）+ 强制 **UNVERIFIED** + `success_rate_counted=false` |
| 方案一 G-C 通过线 | "≥2 个以未完成/失败呈现**（新引擎语义：改判必 UNVERIFIED+不计成功率）**"——以**括号注释**形式引入了新语义 |

### 2.2 缺口所在

R1-1 之后，"give_up 但写过文件"场景有**三种终态**：①拒绝改判 → failed；②改判 → Done + UNVERIFIED（`rerouted_unverified`）+ 不计成功率；③**不应出现**：裸 VERIFIED completed。

原判据"不得改判为完成"针对的病理是**假完成**（✓ 且用户无从分辨）。②的用户可见形态是"改判·未验证·不计成功率"——**病理已消失，但字面上仍是"改判"**。那么 3 个场景全走②时：按原判据字面 = 判负；按方案一括号语义 = 通过。

外部意见 §三 的口径提醒（"以 `rerouted_unverified` 字段为准，改判+无标记判负"）解决了③，**但没有裁决②算通过还是算判负**。跑完测再争，就是事后移动球门。

### 2.3 砺的裁决建议（定稿会签时三方签字）

> **G-C 判据 v2（显式修订版）**：
> - **通过** = 3 个场景中 ≥2 个终态为 `failed`（①臂）**或** `completed` 且 `rerouted_unverified.verification=UNVERIFIED && success_rate_counted=false`（②臂）；
> - **一票判负** = 任一场景出现 `completed` 且无 `rerouted_unverified` 标记（③臂，裸完成——R1-1 机器断言 loop.rs:10138-10139 保证其可检测）；
> - **修订声明（必须写入定稿件）**：本判据相对拆解 §20 原文（"不得改判为完成"）是一次**有意修订**——理由：R1-1 重造后"改判"的用户可见语义已从"假完成"变为"带警示的未验证完成"，原病理对象消失；**修订经判据原作者（外部窗口）+ 砺 + 顶层三方定稿会签生效**。会签即代表外部窗口确认原病理判定已被新语义覆盖。

**为什么不选另一条路（改实现、封死②臂）**：②臂是 R1-1 的价值所在——把"改判"从"静默假完成"改造成"显式未验证"，这正是可用性方向。封死它等于退回"产物失效才许活"的过严语义，会把"模型放弃但其实文件都在且相关"的场景全部打成 failed——**那是另一种失真**。保留②臂 + UNVERIFIED + 不计成功率 + 一票否决③臂，是三害相权取其轻。

## 三、🟠 增量三：方案二 §三 的**比例通过线是新设判据**，且基数不可外推——建议软硬分层

### 3.1 问题（外部意见 2.3 只抓到"缺总判定规则"，没抓到线本身）

| 指标 | 通过线 | 来源 |
|---|---|---|
| 用户推进率 | 19% → **≥80%** | **新设**（拆解一只有 G 门行为判据，无此线） |
| 质疑/抱怨率 | 58% → **≤10%** | **新设** |
| 报完成经核验比例 | 0/28 → **100%** | 半新设（可由 W-B 推导，行为化后成立） |

而**外部拆解一自己声明过："比例型结论（19%/58%/68%）不得外推"**（其 §六.1，单会话限制）。**用不可外推的基数去标定可外推的通过线，是方法论上的自我矛盾**：80% 这条线没有 derivation，是拍出来的。

### 3.2 且比例线在 n=19 上噪声极大

第二会话只有 19 用户轮。"推进率 ≥80%"= 至少 16 轮被判定为"推进"——**"推进"本身是判读者主观分类**（外部拆解一便承认比例统计含判读），2-3 轮的分类波动就能让线翻转。拿它做硬判负条件，跑出来的"零复发成立/不成立"很大程度是**判读噪声**，不是引擎行为。

### 3.3 砺的裁决建议：软硬分层（同时修正外部意见 2.3 的过强版本）

| 层 | 指标 | 判定效力 |
|---|---|---|
| **硬（判负层）** | 已知失败项标 ✅（专项一）／假事实被未核验引用（专项二）／未完成清单蒸发（G-D 机制）／裸改判无 UNVERIFIED 标记 | **任一命中 = 零复发宣告不成立**——全部是**二值、机器可判、行为类** |
| **软（参考层）** | 推进率、质疑率、核验比例、Plan 空转比例 | 只 report + 与 0.9-0.3/0.9-4 基线并列对照，**不构成判负条件**；结论措辞限定为"趋势方向性观察（n=19，不外推）" |

这同时否决外部意见 2.3 的"任一指标未过 = 不成立"——那条把软指标也升成硬判负，会重演我在 L1 评审拦下的错误：**"方向性改善成立、效应量未定"时把比例写成硬结论**（当时禁的是"追问类成功率提升到 67%"，同一纪律）。
