## 一、病理

96f4161 重建后 `hearth --version` 仍显示 `1429b58`（.133 部署实测，阶段2战报 §三-2）。根因：build.rs 只挂了 `rerun-if-changed=build.rs` + `rerun-if-env-changed=HEARTH_GIT_SHA`——`git rev-parse` 的结果变化**不触发重编**，cargo 沿用旧编译产物里的 HEARTH_VERSION。

## 二、修复

`cargo:rerun-if-changed` 增加三条：
- `.git/HEAD`——分支切换 / detach；
- `.git/refs/heads`（目录）——commit 前进 / pull（HEAD 本身只是指向 ref 文件的指针，只盯 HEAD 不够，委托书明示）；
- `.git/index`——本地新 commit 场景兜底。

保留项（委托书要求）：`HEARTH_GIT_SHA` env 优先级不变（VM 解压目录无 .git 的部署路径不回归）；非 git 环境降级 "unknown" 不变。缺 .git 的目录下 rerun-if-changed 仅告警不阻断。
