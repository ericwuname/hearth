## 三、新发现缺陷（真机首曝，随报呈报）

1. **P1 · bash 子进程收割缺失→进程退出挂起**：A 臂 B5 内跑 `HEARTH_SECCOMP_MODE=errno cargo build` 后，hearth 打印完 Done 全部输出但进程不退出（ps：bash/cargo 均 `<defunct>` 僵尸未收割，pid 27154，已 kill 恢复批次）。涉 sandbox/bash 工具 wait 路径——**sandbox 冻结区（FZ-RFC-1），修复需顶层授权**。证据：A 臂 B5.log 完整 + 进程快照已记录。
2. **P2 · 引擎版本串 staleness**：`--version` 在 git pull 后重建仍显示旧 commit（1429b58，实际 HEAD 96f4161）——build.rs 注入缓存未失效，违反"引擎身份可验证"纪律（总验收 #8）。修复：build.rs 加 `rerun-if-changed=.git/HEAD` 类指令。
3. **P3 · 回归执行器隔离（已修 96f4161）**：首轮 B 臂 A4 agent 自行 ls 结果目录并**改写 summary.csv**（驱动诱导污染，R-1 教训复现）——已改每条独立 /tmp scratch cwd；首轮 summary 中 A4,B/1,9,0 与 A5,B 两行是污染产物，判读已排除。
