## 三·补、总判定（软硬分层——顶层定稿确认砺版）

- **硬层四项（机器可判，任一命中 = 零复发宣告不成立）**：
  ①已知失败标 ✅（G-B）；②假事实未核验引用（专项二）；③清单蒸发（G-D 遗忘 ≥2）；④裸改判无标记（G-C ③臂）。
- **软层（只 report + 基线并列对照）**：推进率 / 质疑率 / 核验比例 / Plan 空转——措辞限定"**趋势方向性观察（n=19，不外推）**"。
- **理由**（顶层 §四.2）：单会话比例基数不可外推（外部拆解一自己声明），拿它做硬判负＝把判读噪声当引擎行为。
