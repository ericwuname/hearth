## 3. 暗色配色体系（方法论，供后续窗口复用）

1. **变量层**：`:root` 定义浅色 + `[data-theme="dark"]` 覆写暗色；`toggleTheme()` 只翻转 `data-theme`（FE-only，不进后端事实）。
2. **`-soft` 规则**：`--accent-soft` / `--pur-soft` 在暗色下**保持浅值**（浅药丸 + 深字），保证跨主题可读；这是"浅字 + 深底"的唯一合法浅底场景。
3. **防御性皮肤层**：`[data-theme="dark"] .card / .msg-ai .bubble / .hsb / .rsb / .sb / .modal { color:var(--tx) }`，关键容器显式深底+浅字，不依赖继承（textarea 等不继承 body 色的元素尤其要吃这一层）。
4. **暗染底模式**：选中项、状态徽章统一用 `rgba(...,.16~.18)` 半透明深染，而非浅实底，浅字在深底清晰可读。
5. **顺序陷阱（血泪）**：带 `[data-theme="dark"]` 前缀的暗规则，**必须出现在"后文浅色规则"之后**才能压过它（CSS 源码顺序决定优先级，同特异性下后者胜）。绿差异行 `.dl.add` 即因漏前缀被后文浅色覆盖——这是变量层之上独立的"源码顺序"问题，审计时单看变量层会漏判。
