## 2. 规划锚点（决策过滤器，不可动摇）

- **终点 Telos**：长周期可信委托 + 不可绕过硬边界。（不是跑分更高、治理更厚。）
- **三滤**：必要（G0 硬牙齿 / G1 断言常绿 / 人硅边界 / 干净基线）> 有益可等（旧债 / 对外 RFC / 守夜层 / guest）> 停止（embedding 精炼 / 新治理 RFC 主动提案 / 跑分优化）。
- **增量边界**：维护期只做稳定化与红线响应；功能新增须经红线触发或有可测量靶心。
