## 第 3 层 · 三条证据链（本轮最重要产出）

### ⭐ 链① 压缩 → 假完成 → 用户当场发现复发（RC37）

`手工测试v0.2.10.txt` L621–L639 完整现场：

```
L624  ┌─ 🗺 规划草案（steps=1 gaps=1 待问=0 自动假设=1）
L625     ⚡ 假设[missing_goal_source]: 目标未标注来源…
L626     · 检查之前的交互日志和系统状态，分析为什么用户询问'有没有相干的'时没有输出内容 [Pending]
L631  [compacted 会话摘要] 轮次目标: Text("我继续，你想做什么") | 工具: 无 | 写盘: 无 ✓ Done (2 steps)
L632    📄 执行报告: …/run-017.md
L633    ✓ Task completed（2 步）——目标达成，产物见报告
L635  hearth> 〉又出现相同的问题了。
```

**链条**：上下文被压缩成一条 **60 字墓碑**（"我继续，你想做什么"，无工具无写盘）→ 规划草案只剩 **1 步** → 系统报 **✓ Task completed 目标达成** → 用户 2 行之后立刻说 **"又出现相同的问题了"**。

**判读**：这是 RC5（压缩=信息销毁）× RC21（假完成）的**复合现场**，且是本次语料中"系统自报成功 vs 用户体感"背离最刺眼的一处——**在上下文已被销毁的状态下，系统依然自报成功**。

### ⭐ 链② 连续性追问被 Goal Revision 全数吞掉（RC36）

v0.2.10 中用户 **8 次** 追问"你还记得我的第一个问题吗"（L297 / L358 / L1206 / L1784 / L2309 / L4396 / L5044 / L5099）。
**每一次的系统响应都是同一形态**：

```
🔁 目标已修订（revision N）：<用户原话被截断>——原目标保留为锚点
```

即：**用户的问题被当成了"目标改版"，而不是"一个需要回答的问题"**。系统随后去"执行这个目标"，而不是回答"我记得/不记得"。

- RC31 的 original_goal 锚保护**生效了**（"原目标保留为锚点"）；
- 但**没有保护"回答用户"这个行为本身**——提问被改写成目标，答案从未产出；
- 结局：L5099 用户放弃追问，**反过来告诉 agent 答案**「我告诉你我问你的第一个问题…问题是：你知道你是谁吗」——**8 次追问，0 次被回答**。

这条把 RC33（revision 爆炸）从"频率异常"升级为**机制性缺陷**：Goal Revision 对"疑问/追问/元访谈"缺少豁免。

### ⭐ 链③ 输出 200 字截断（RC35）

- v0.2.10 中 **92 行**以 `…` 结尾（v0.2.8 76 行）。抽样（L342–344）均为**工具输出**：
  `codex_work/bench/tasks/T04-json-output/fixture/src/lib.rs\ncodex_work/bench…`
- 来源：`render.rs` `tool_result()` 的 `output.chars().take(200)` ——**有意为之的显示截断**，但：
  1. 对 agent 而言，看到的路径/内容是**半截**的（"codex_work/bench…"），易诱发路径误读；
  2. 与 v1 记录的**静默截断族**同源：web 8000 / context 摘要 60 / constitution 6000 / RAG query 200 / render 200 —— **共 5 处，全部无截断标记**。
- 用户明确抱怨过一次：L3909「你回复了，但是没有回复完全」。

### 附带：内部脚手架文本外泄（RC38）

L3909 / L3911 / L3932 出现 `✓ [INTERNAL REFLECTION — Step 3 of 100]` —— agent 把内部推理脚手架**当成回复正文输出给用户**。同一处用户还指出"后面全是任务失败"。

## 验收判据（回归清单 · 目标：这些问题不再出现）

> 原则：**先红后绿**。每条判据在修复前必须能失败；禁止只改现象不改判据。

| ID | 判据 | 覆盖 |
|---|---|---|
| **A-37** | 构造会话使其触发压缩（>32k 字符），压缩后系统**不得**在无有效产物/无回答时报 `✓ Task completed`；若上下文已销毁到只剩摘要，终态须为 `partial/needs_reconfirm` 并显式提示"上下文已压缩，请确认是否继续" | RC37 |
| **A-36** | 用户连续 3 次输入纯疑问（"你还记得 X 吗"），断言：**不得产生 GoalChanged 事件**，且 agent 必须给出针对该问题的回答（可断言回答中含/不含特定事实） | RC36 |
| **A-36b** | 单会话 `revision` 增量 > 20 时，须输出告警；纯追问/解释/元访谈不计入 revision | RC33/36 |
| **A-32** | 构造"首次调用失败、重试即成功"的任务：连续 2 次同构 TaskGraph 但**有工具成功/有新事实**时，**不得**触发 stalled give_up | RC32 |
| **A-35** | 工具输出被截断时，输出中必须带显式标记（`…[截断 N→200 字符]`），且结构化字段含 `truncated: true` + `original_chars` | RC35（与 TC-5 合并） |
| **A-38** | 用户可见输出中不得出现 `[INTERNAL REFLECTION`、`[Step N of` 等脚手架前缀（渲染前过滤 + 单测） | RC38 |
| **A-5** | 连续对话 ≥ 8 轮后，agent 能复述第 1 轮用户给出的关键事实（这是用户自己在测的验收项） | RC5 |
| **A-30** | 压缩点前后"重复命令计数"不得上升 | RC30 |
| **A-24b** | `echo hi >/dev/null; echo WRITE_RC=$?` 必须得 `WRITE_RC=0` | RC24-B |
| **A-26** | 单份规划草案中 `missing_goal_source` **最多出现 1 次** | RC34 |
