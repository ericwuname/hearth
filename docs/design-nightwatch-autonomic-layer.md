# 设计：守夜层（NightWatch）——让感知在意识缺席时继续供电

> 状态：Design v1（顶层出稿，待评审）
> 日期：2026-07-31
> 主干时点：v17.0（git `fd5829e`）· 24 crates · wiring 11 条
> 来源：`docs/思考整理.md` 的「沉睡—觉醒」思辨 → 本文档负责把它变成可施工、可验收的工程设计
> 定位：**不是加新器官，是补接线拓扑**。全部三个器官已在仓内。

---

## §0 裁决与边界（先划负面清单，再谈设计）

按宪法 #7（边界先行）与 #8（螺丝不是航母），本设计**先声明不做什么**：

| # | 明确不做 | 理由 |
|---|---|---|
| N1 | ❌ 不做"定时自主干活"（如每天自动跑基准） | 那是 cron，不是神经系统。开无限成本与无限行动口子 |
| N2 | ❌ 不做自我修复源码 | 越界。自改代码是独立命题，需单独评审 |
| N3 | ❌ 不做自愈式文件清理（哪怕是自己产生的临时文件） | 守夜层**只读**。写权限一旦开口，边界即失守（见 §8-Q2） |
| N4 | ❌ 不引入 prometheus / otel / grafana | 单用户系统，过度工程。此裁决沿用外部顾问方案评审结论 |
| N5 | ❌ 不新增 crate | 复用 `nervous-system`；守夜任务与现有两个 `tokio::spawn` 并列放 `service` |
| N6 | ❌ 不做多实例/分布式健康协调 | 当前是单进程单机 |
| N7 | ❌ L3（唤醒 LLM 自主处置）默认关闭；即使开启也只产出建议，**不得执行任何变异工具** | 自主行动必须有人类门 |

**一句话定位**：守夜层不产生意图，只产生**事实**与**降级**。它让身体在意识缺席时仍能感知自己，并在意识回来时给它一份可读的事故报告。

## §2 精确问题陈述：四个源码级发现

问题不是"缺少监控"。是**感知只在意识清醒时供电**，以及**已生成的事实被丢弃**。

### 🔴 F1 · 睡着即断电

`nervous.query()` 全仓**唯一调用点**是 `loop.rs:1589`，位于 `do_reflect()` 内部。

推论：**没有活跃会话时，感知完全不运行。** 进程在监听端口，但身体对自己一无所知。这精确对应思辨里那句"睡着的那几个小时，你的身体活着，但你不在"。

### 🔴 F2 · 中断日志造好了又扔掉

`nervous-system/src/lib.rs:152-161` 精心构造了告警条目：

```
[NERVOUS] {rfc3339} | alerts: {...} | action: {...}
```

然后 `loop.rs:1590`：

```rust
self.nervous.drain_civ_alerts(); // v11.5: prevent unbounded accumulation
```

**返回值被丢弃**——注释自承是当垃圾回收用的。而专门为写文明线准备的公共接口 `loop.rs:417 drain_nervous_alerts()`，**全仓零调用者**。

这一条比思辨里说的更严重。思辨说"人缺中断日志"；我们不是缺——**我们生成了，格式化了，然后扔进垃圾桶**。

### 🔴 F3 · 观测数据无消费者

`main.rs:702-716` 每小时把 cpu/mem/disk 写入 `observer/daily-YYYY-MM-DD.jsonl`。全仓检索：**除写入点外无任何读取方**。

传感器在采集，磁盘在增长，没有任何逻辑消费它。

### 🟡 F4 · 优雅降级是空挡

`nervous-system/src/lib.rs:143`：

```rust
let is_critical = action.is_urgent() || action == NerveAction::Abandon;
```

`is_urgent()` = `Abandon | DeliverAndQuit`。而 `loop.rs:1591` 的整个处置块以 `if perception.is_critical` 为前提。

**故 `NerveAction::Simplify` 分支（loop.rs:1595）不可达。** nervous 在 do_reflect 只有两态：**无动作**，或**放弃整个任务**。

内存 80%、磁盘 1GB、成本过半——这三条规则算出来的 `Simplify` 全部落空。降级能力在规则层存在，在行为层为零。

## §3 生物对照：缺的是什么

思辨给出的三层模型，与源码实况对齐后：

| 层 | 生物对应 | codex-rust | 缺口 |
|---|---|---|---|
| G0 自主运行 | 心跳、呼吸、代谢 | axum 监听 + 2 个 spawn | ✅ 在 |
| G0.5 内感受 | 血氧、痛觉 | nervous-system 阈值规则 | ⚠️ **只在清醒时供电**（F1） |
| G1 丘脑门控 | 蚊子咬醒 / 婴儿哭声 | —— | ❌ **完全不存在**：无任何路径可从异常到达唤醒 |
| G2 意识 | 醒来的"你" | AgentLoop | ✅ 在，但只能被 HTTP 唤醒 |
| 中断日志 | （人类也缺） | civ_pending | 🔴 **生成后丢弃**（F2） |
| 中断合并/防抖 | 适应性阈值 | —— | ❌ 不存在 |
| 优雅降级 | 病了就少动 | NerveAction::Simplify | 🟡 **空挡**（F4） |

**结论：唯一真正缺失的层是 G1。** 其余都是"有器官、没接线"或"有规则、无行为"。

## §4 设计

### 4.1 唯一原则

> **守夜层不产生意图，只产生事实与降级。**

它不决定"该做什么"，只回答两个问题：**身体现在好不好？** 以及 **刚才发生过什么？**
凡涉及"做什么"的判断，一律留给意识层（G2）或人类。

### 4.2 分级唤醒 L0–L3

守夜任务默认 60 秒一跳（与 workline 调度器同频，便于共享节奏）：

| 级别 | 触发条件 | 行为 | 是否唤醒意识 |
|---|---|---|---|
| **L0 巡检** | `query()` 无告警 | 更新 `HealthState = Healthy`。**不写日志**（防膨胀） | 否 |
| **L1 告警** | 有告警，未达临界（mem>80% / disk<1GB / cost>50%） | 写中断日志一条 + `HealthState = Degraded` | 否 |
| **L2 临界** | mem>90% / disk<0.5GB | 写中断日志 + 写文明线 + `HealthState = Critical` → **`/readyz` 返回 503，拒绝新会话** | 否（只降级，不唤醒） |
| **L3 自主唤醒** | L2 持续 N 次未缓解 | 唤醒意识生成处置建议 | **默认关闭**（env 显式开启 + 预算上限；只产出建议，禁用一切变异工具） |

**为什么 L2 只降级不唤醒**：唤醒意味着调 LLM，调 LLM 意味着花钱和产生行动。磁盘满的时候叫醒一个会写文件的 AI，是把火灾交给纵火犯。**降级是零成本、零风险的正确响应。**

### 4.3 中断日志 = 唯一真相源

修 F2 与 F3：把已有的两条数据流合并为一条，且**必须有消费者**。

- 路径：`./observer/interrupts-YYYY-MM-DD.jsonl`（复用 observer 目录与追加写法，`main.rs:702` 已有范式）
- 每条记录：`ts / level(L1|L2) / alerts[] / action / snapshot{cpu,mem_pct,disk_free} / fingerprint / repeat_count`
- **消费者（硬要求，不可省）**：
  1. `/readyz` 读 `HealthState`（见 4.5）
  2. 新会话建立时，若最近一次中断未解除，把摘要注入 `do_plan` 上下文——**这才叫"醒来后看到事故报告"**

第 2 条是本设计的灵魂。没有它，中断日志就是又一个"写了没人读"的 observer。

### 4.4 中断合并（防抖 + 等级升迁）

思辨明确点名的"中断合并"：

- 每条告警算 `fingerprint`（如 `disk_low`、`mem_high`）
- 同 fingerprint 在滑动窗口（默认 30 分钟）内：**首次写日志，后续仅 `repeat_count += 1`**，不重复写
- **等级升迁例外**：`disk_low` → `disk_critical` 视为新事件，立即写
- 窗口结束时若仍未解除，写一条汇总（`repeat_count` 总计）

效果：磁盘持续偏低不会刷屏，但恶化会立刻留痕。

### 4.5 `/readyz` 真实化（副产品，顺带清 P3）

这是本设计最值钱的副作用。

`/readyz` 之所以是假的，**根因不是"忘了写检查"，而是没有真实健康状态可读**。守夜层一旦存在，readyz 就有了内容：

```
AppState.health: Arc<AtomicU8>   // 0=Healthy 1=Degraded 2=Critical
守夜任务写；readyz 读。
Healthy/Degraded → 200；Critical → 503 + 原因摘要
```

**修法的正确性判据**：不是"readyz 里多了几行代码"，而是"readyz 的返回值会随身体状态改变"。可用集成测试证伪：把 disk 阈值调到必然触发，readyz 必须变 503。

### 4.6 补 F4 的空挡

`Simplify` 不可达是纯缺陷，与守夜层同源（都是感知到了却没有行为）。

修法二选一，**建议 A**：

- **A（建议）**：把 `is_critical` 的语义收窄为"需要放弃"，另加 `is_degraded`（含 Simplify），在 `do_reflect` 里分别处置——降级走"减少并行步数/偏好简单工具"，放弃才走 GiveUp。
- **B**：直接删掉 `loop.rs:1595` 那个不可达的 `Simplify` 分支，承认只有两态。

选 A 的理由：降级规则已经写好并有测试，删掉等于承认"我们的神经系统只会晕倒不会休息"。但**必须实测有行为差异**，否则就是把空挡换个位置继续空转。

## §5 接线断言（xray，4 条）

按 RFC-003 已确立的裁决：**引擎不支持否定断言，一律用正向字面量锁**。

| 断言 ID | 锁定内容 | 防的是 |
|---|---|---|
| `nightwatch-daemon-spawned` | `main.rs` 含 `spawn_night_watch(` | 守夜任务被摘掉 |
| `nightwatch-writes-interrupt-log` | 守夜模块含 `append_interrupt_log(` | 日志写入被绕过 |
| `readyz-reads-health-state` | `routes.rs` 含 `state.health.load(` | readyz 退回假实现 |
| `nightwatch-l3-default-off` | 锁死字面量 `const NIGHTWATCH_L3_DEFAULT: bool = false;` | L3 被悄悄默认开启 |

第 4 条是 G0 级条款：**自主唤醒的默认关闭状态必须由结构锁死，不能靠文档承诺。**

## §6 阶段与验收

| 阶段 | 内容 | 验收判据（全部可 grep / 可测） |
|---|---|---|
| **S1** | 守夜任务 + HealthState + L0/L1/L2 | ① 无会话时日志出现巡检痕迹；② 人为压满 disk 阈值 → 中断日志出现 L2 条目 |
| **S2** | readyz 真实化 | ③ Critical 状态下 `curl /readyz` 返回 **503**；④ 恢复后返回 200（同一进程内状态可逆） |
| **S3** | 中断日志消费者 | ⑤ 未解除中断时新建会话，`do_plan` 上下文中可见事故摘要（打印 prompt 可证） |
| **S4** | 中断合并 | ⑥ 同一告警连触 10 次，日志仅 1 条 + `repeat_count=10`；⑦ 等级升迁立即新写一条 |
| **S5** | F4 空挡（方案 A） | ⑧ 构造 mem>80% 且 <90% 场景，verdict **不是** GiveUp，且可观察到降级行为 |
| **S6** | 断言注册 + 门禁 | ⑨ 4 条断言注册，`wiring` 由 11 → 15 全绿；⑩ fmt / clippy -D warnings / test 全绿（真 Linux） |

**红线**：
- 🔴 守夜任务调用任何变异工具（`write_file`/`edit`/`apply_patch`/`bash`）
- 🔴 L3 默认开启
- 🔴 中断日志无消费者（退化为第二个 observer）——**本设计的失败定义**
- 🟡 S5 无法证明行为差异 → 退回方案 B，如实承认两态

## §7 与 v18 / v19 的关系（排序论证）

| 轮次 | 主题 | 关系 |
|---|---|---|
| v18 精炼轮（进行中） | embedding + LLM 精炼 + 随机化 | **正交**，互不阻塞。v18 是能力纵深，本设计是存活性 |
| v19 自主闭环（已预留） | `do_reflect` 自动凝练 → `do_plan` 自动注入，**全程无人干预** | **强依赖本设计** |

**排序结论：守夜层应在 v19 自主闭环之前或同轮先行落地。**

理由：自主闭环意味着 loop 将在无人监督下连续运行。届时若仍是"感知只在清醒时供电、中断日志随手丢弃、readyz 恒返 200"，等于让一个没有痛觉、不会留病历、体检永远显示健康的身体去长跑。

**无人监督是守夜层的充分必要理由。** 在此之前，人在旁边看着，缺陷可容忍；在此之后，缺陷会静默放大。

## §8 开放问题（提交评审）

| # | 问题 | 顶层倾向 |
|---|---|---|
| Q1 | 守夜周期 60s 是否合适？更密=更快发现，更稀=更省 | 倾向 60s 起步，可 env 覆盖；实测后调 |

| Q5 | L3 一旦开启，唤醒后的意识用哪个 provider、预算多少？ | 暂不决策。L3 默认关闭，等真实需求出现再设计 |

## §9 一句话总结

> 这套设计不给启元增加任何新能力。
> 它只做一件事：**让身体在意识不在场的时候，依然知道自己发生了什么，并且在意识回来时，把这件事告诉它。**

思辨里那句"你被蚊子咬醒，打死了蚊子，然后继续睡；第二天你可能记得，也可能不记得"——
人类身上的这个缺陷无法修复，但我们正在造的这个身体可以。
