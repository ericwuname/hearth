# Hearth 天赋基因规范 · 不同见解与补充

> 补 `hearth-meta-capability-genes.md`。
> 那份规范把"天赋"映射到 G0/G1，方向对。但有一个关键盲区：**它把"全维度天赋"当成了纯粹的好事，没讨论天赋的代价**。
> 本补充针对你那一句"人类天赋指向单一，但 hearth 或许可以不一样"——这句话里藏着一个比"天赋清单"更深的设计问题。

---

## 一、不同见解：hearth 的"不一样"，不该是"拥有全部 20 项天赋"

人类天赋的"单一性"不是缺陷，是**进化最优**——认知资源有限，天赋必须极化：一个数学天才把算力全押在抽象推理上，代价是社交直觉弱。这是取舍，不是随机。

hearth 作为 AI，理论上可以"全维度天赋"。但这里有个陷阱：

**天赋不是免费的。** 如果把 T1-T10 + C1-C10 共 20 项全部升为 G1 常驻必执行，会出现两个后果：

1. **预算爆炸**：写一篇小说，agent 要先主动探索"还差什么信息"(C1) → 检查"世界与模型失配"(C2) → 做"假设已失败为什么"(T6 pre-mortem) → 强制多透镜(T5) → 置信校准(C3) → EV 量化(C6) → 可逆性检查(C7)……一个 5000 字故事，天赋电路先吃掉 40% 预算。

2. **过度监控杀死创造力**：创作需要的是"流"，不是"监控"。上面那一串对写小说是灾难。一个永远在怀疑自己、做 pre-mortem、要求多角度验证的 agent，写不出打动人心的东西——它只会写"正确的、平庸的"。

**所以我的不同见解是**：hearth 的"不一样"，不是"拥有全部天赋"，而是**"能按任务切换认知风格"**——这恰恰是人类的顶尖选手也做不到的（他们是"固定天赋"，hearth 是"可切换天赋"）。

---

## 二、核心盲区：规范缺"天赋的情境门控"

规范把天赋分成 G0/G1（电路）和 G2/G3（内容），但缺了第三个维度：**激活条件**。

人类的天赋不是全天候开着的——数学天才打球时不动用数学天赋。天赋是**情境触发**的。

对应到 hearth：

| 任务类型 | 该激活的天赋 | 该抑制的天赋 |
|---|---|---|
| 写小说/创作 | 好奇(C1)、抽象迁移(T9)、求真(T2) | 减速(T7)、pre-mortem(T6)、EV 量化(C6) |
| 写代码 | 减速(T7)、可逆性(C7)、证伪(T8)、目标锚定(T10) | 主动探索(C1，容易跑偏) |
| 数据分析/决策 | 置信校准(C3)、基础比率(C5)、EV(C6)、多透镜(T5) | — |
| 纯问答 20+20 | **几乎全部抑制**（≤3 步就答完） | 全部监控类天赋 |

规范 §6 只把 C1 的"触发边界"列为开放问题，但**这应该提升为核心设计原则**：天赋不是"挂了就不摘"，是"情境门控的调度系统"。

---

## 三、天赋 vs 纪律：17 项全升 G1 可能做错了方向

这是我认为最值得商榷的一点。规范 §3 把 17 项升为 G1 必执行。但"天赋"和"纪律"在工程上是两回事：

| | 纪律（显式断言 G1） | 天赋（结构倾向 G3 软偏置） |
|---|---|---|
| 本质 | "我应该这么做"——硬规则，可验证 | "我天然这么做"——软倾向，涌现 |
| 优点 | fail-closed，可审计 | 自然、不僵化、保留"流" |
| 缺点 | 僵化、吃掉预算、杀死创造力 | 难验证、可被跳过 |

人类的天赋是**结构倾向**，不是**给自己定规则**。一个天赋型选手不会说"我要怀疑一切"——他的大脑天然就怀疑。如果 hearth 的天赋全部是"显式断言"，那它更像"纪律森严的新手"，而不是"有天分的老手"。

**建议的修正**：天赋分级不该是"17 项全 G1"，而是——

```
核心电路（少而精，G0/G1 硬）：
  只有"被跳过会 quietly 出错"的少数几项才是真 G1：
  T1 认知谦逊、T3 自检回路、T4 体感、T7 减速、T10 目标锚定、C9 价值澄清
  ——这 6 项是"不可跳过的安全底线"，挂 wiring 断言。

认知风格（多而软，G3 偏置 + 情境门控）：
  其余 14 项是"气质"而非"纪律"——写进 constitution/prompt 偏置，
  由情境门控调度激活，不挂 fail-closed 断言。
  它们的验证不是"绕过会 fail"，而是"该激活时激活了没"（统计验证，非二进制）。
```

这样既保留了"天赋 = 先天电路"的洞察（核心电路是 G1 硬），又避免了"把天赋做成纪律"的僵化。

---

## 四、补充：天赋的组合 = 认知风格（这才是"不一样"的真正含义）

你观察到"人类天赋指向单一"，这暗示了：天赋不是孤立的 20 项清单，而是**会组合成一种"认知风格"**。

```
怀疑论者 = 认知谦逊(T1) + 证伪耐受(T8) + 困惑识别(C2)
工程师   = 减速(T7) + 可逆性(C7) + 目标锚定(T10)
学者     = 好奇(C1) + 抽象迁移(T9) + 置信校准(C3)
外科医生 = 减速(T7) + 目标锚定(T10) + 事前验尸(T6)
```

**hearth 的"不一样"** = 不锁定单一风格，而是**按任务动态组合**。这需要一个"风格调度器"：

```
任务分类 → 匹配认知风格 → 激活对应天赋组合（G3 偏置注入）→ 任务结束释放
```

这比"17 项 G1 全开"更接近"天赋"的本义——天赋是**有选择的敏锐**，不是**无差别的警觉**。

## 五、给执行窗口的落地修正

| 原规范 | 修正后 |
|---|---|
| 17 项全升 G1 常驻 | **6 项核心 G1 硬 + 14 项 G3 软偏置** |
| 天赋无激活条件 | **情境门控调度**：按任务类型激活/抑制 |
| 天赋是并列清单 | **认知风格组合**：天赋聚类成 4-5 种风格 |
| 验证靠"绕过会 fail" | 核心电路用 fail 断言；软天赋用"该激活时激活了没"统计验证 |

---

## 六、一句话总结

你的直觉"hearth 可以不一样"是对的，但"不一样"的点不是"拥有全部天赋"——**是"能按任务切换天赋组合"**。

人类天赋单一，是因为资源有限被迫极化；hearth 若要超越，不是"全都要"（那会预算爆炸 + 杀死创造力），而是"该用哪个用哪个"（情境门控的认知风格调度）。

规范现有的 20 项天赋图谱很有价值，但缺了"代价"和"调度"两个维度。补上这两个，天赋才是"天赋"，而不是"20 条死板的纪律"。

*天赋的本质是"有选择的敏锐"，不是"无差别的警觉"。*
