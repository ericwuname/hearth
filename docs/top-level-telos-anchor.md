# 顶层设计战略锚点：终点、决策过滤器与增量边界

> 缘起：主理人反馈——聊了很多、落地少；信息越多决策越难；难在不知道哪个决策是对的。本锚点不从执行层回应，而从高维视角把决策空间**坍缩**，给出可据以判断的终点与边界。本文件是「减项」，不是「加项」。
> 作者：顶层架构角色 · 2026-07-31

---

## §0 诊断：瘫痪是结构性的，不是你的问题

信息量↑ 与 决策质量↓ 同时发生，说明我们一直在**局部优化**（每一轮、每一份 RFC 各自成立），却缺一个**全局目标函数**。没有目标的局部最优 = 漂移。补更多 RFC / 更多轮次只会继续加噪。

解法不是「再想清楚一点」，而是**先把终点钉死**——终点一旦明确，绝大多数决策会变成机械判断（「它离可信委托更近还是更远？」）。

---

## §1 终点（Telos）：一句话

**codex-rust / 启元 的终点是——一个人类可在长周期里放心委派真实、开放编码工作的自主工程实体，具备（a）不可被静默绕过的硬安全边界、（b）人类可审计的透明自治、（c）硅基能动性与人类权威之间被尊重的清晰边界。**

终点**不是**「能力更强」「跑分更高」「治理更厚」。那些是通向终点的**手段或副产品**，不是终点本身。任何不增加「可信委托」的事，都是噪音。

---

## §2 决策过滤器（必要 / 有益 / 停止）

**必要（不动终点就不存在，优先级最高）：**
- 已证编码能力（基准 95–100%）——维持，不扩张
- 硬牙齿 G0：sandbox / landlock / seccomp + 审批门 + 进程隔离——已建，守住
- 真治理牙齿 G1：11 条 xray 接线断言必须常绿——这是安全「真有牙」而非 cosplay 的唯一证据
- 人硅边界（CN-001 精神）——方向性锚，不可交易
- 一个干净可发布的基线（当前 v18 半提交、半跑完 = 不稳定态，必须先稳定）

**有益但非必要（优化 / 探索，可等）：**
- 经验回路精炼 / embedding（v18）——已被 v18 自身证据质疑（E0=87.5% ≫ v17-R1 65%，疑似顺序效应）；只有证明真提升可信委托才值得
- 输出经济性（RFC-004）——质量优化，非终点必需
- 决策惯性（RFC-005）——智慧优化，但其「G0 冷却期」是假 G0
- 更多治理层 / 更多 RFC——**在目标函数缺失时是净负**：每加一条无牙的「齿」= 假安全（readyz 先例），比没有更糟

**停止（增量边界之外）：**
- 🛑 在 G0–G3 语汇未对外统一前，不再接收新治理 RFC（约定文档已兜底，但新提案仍应暂停）
- 🛑 在顺序效应混杂变量未清除前，不再优化经验回路 / embedding（当前「回路」可能不存在）
- 🛑 不再把跑分 % 当目标——它是门槛，不是目的地

---

## §3 增量边界：下一步只做「稳定化」

下一步的正确增量不是「加」，而是「收口」：
1. 把 v18 收尾或显式冻结（补跑 E3 或明确 park；commit + tag 一个干净基线）
2. 在稳定基线上确认 11 条断言 + G0 sandbox 仍真咬合（防 v18 embedding 改动静默破坏）
3. G0–G3 语汇对外已统一（约定文档就位），新 RFC 按模板走
4. **然后暂停功能新增**，先定义「可信委托」的可测量靶心，再谈优化

---

## §4 决策坍缩：把 ~10 个开放线程收到 4 个承载性决策

| # | 决策 | 推荐默认（若你认 §1 终点） | 为什么它承载方向 |
|---|---|---|---|
| **D1** | 终点是否 =「长周期可信委托 + 硬边界」？ | ✅ 是 | 它是一切过滤器的前提；不认就先谈这个 |
| **D2** | 现在是否稳定并发布一个干净 v18 基线？ | ✅ 是（先收口，别再实验） | 消除「半提交不稳定态」，让后续判断有锚 |
| **D3** | 是否对新治理 RFC 按下硬暂停，直到有可测量靶心？ | ✅ 是 | 阻止净负噪音（假安全层）继续堆积 |
| **D4** | CN-001 是否以 CN 层元规范接受？ | ✅ 是（低成本高象征） | 把人硅边界钉为方向锚，零强制力无风险 |

其余（RFC-004 v3 / RFC-005 替代路径 / embedding 投入 / 经验精炼）全部降为 **B 级待办，等 D1–D3 落定后再排**——它们不再并行占用你的决策带宽。

你不需要再「想清楚每件事」。你只需对 D1–D4 点头或改默认。其余由我按角色纪律转为设计 / 任务书，不占用你的判断。

若 D1 你有不同的终点定义，**那一句话就是当前唯一该先澄清的**——它决定后面所有过滤器。
