## §0 一句话结论：数据替我们做了一个"停止"决策

v15→v18 连续四轮在"经验回路"上投入（embedding / LLM 精炼 / 自主凝练闭环），最终对**生产标准脑(deepseek)** 的净收益 = **0，甚至 −5pt**。这恰好是 `telos-anchor` 警告过的"无目标函数的局部最优 = 漂移"的活样本。但它的价值在于：**它一次性砍掉了 embedding / 精炼 / 自主闭环一整条未来工作线**——你不必再为"要不要继续投经验系统"纠结，数据替你说了停。

## §1 对"经验无效性"的精确读法（避免误读成"全部推翻"）

用户原话"经验无效性"略带恐慌，需精确化：

| 说法 | 准确吗 | 修正 |
|---|---|---|
| 经验完全无效 | ❌ | 经验**对弱模型(zhipu)有效 +20pt**（v17 真结论） |
| 经验对强模型无效 | ✅ | deepseek(87.5%)：E0=E1 零增量，E2/E3 略降 → 噪音/干扰 |
| 所以经验系统是错的 | ❌ | 经验系统的**正确形态 = 可选降级通道**（模型弱/连续失败才注入），非常驻增强 |

**机制（报告+审计）：** 强模型本来就会做 → 注入的经验是泛泛建议 → 污染 prompt 干扰推理。弱模型不会做 → 经验给具体修复步骤 → 提分。**适用域 = 模型能力 < 任务难度。**

⚠️ **两点诚实保留：**
1. "provider 相关"的 zhipu 一侧在 v18 **未被复跑**（计划用 zhipu 可比，实际全用 deepseek，见 plan §3 偏离）。v18 证的是"deepseek 无效"；zhipu 有效是 v17 未复现的声称（审计 D1）。但本项目标准脑是 deepseek，故实践结论无碍。
2. E2/E3 微降的"干扰推理"机制是假设（审计 D2 未日志级证实），不影响"无增量"的结论。

## §2 用 telos 过滤器重排所有开放线程

终点 = **长周期可信委托 + 不可绕过硬边界**（待 D1 确认）。三滤：

| 线程 | 过滤结果 | 理由 |
|---|---|---|
| embedding 语义召回 | 🔴 **停止** | E3 82.5% < E2 85.0%，零增量 |
| LLM 经验精炼 | 🔴 **停止** | E2 85.0% < E1 87.5%，零增量 |
| 自主凝练闭环(do_reflect 自动) | 🔴 **停止** | 前提是经验有用，对强模型前提不成立 |
| G2 常驻注入 | 🔴 **停止** | 改为降级通道 |
| **收口 v18 为干净基线** | 🟢 **必要** | 结束悬空 WIP，固化"否定性发现"里程碑 |
| **回退 embedding 死代码** | 🟢 **必要·减债** | 无增量 + 含硬编码 key（债务 🔴），回退即消除 |
| **写"经验回路适用域"设计决策** | 🟢 **必要·顶层文档** | 把实证落成架构决策，非业务代码 |
| T13/T19 能力墙 | 🟡 **有益·可等** | deepseek 也挂，优先级 > 经验回路，但属"能力"非"边界" |
| CN-001 / RFC-004 v3 / RFC-005 替代路径 | 🟡 **暂停** | 等 D1-D4 拍板，不并行占带宽 |
