## §1 项目背景与两个总包的关系

### 1.1 Hearth 是什么

| 项 | 值 |
|---|---|
| 形态 | Rust 自研 coding-agent harness（对标 Codex CLI / Claude Code） |
| 规模 | **27 crates**，主循环 `crates/agent-core/src/loop.rs` 约 10,200 行（外部报告计数），生产区约 5,070 行 |
| 目标 | "在弱 LLM 下也能交付高质量"——PDCA 相位循环 + 三端口架构（Human OS / AI OS / Observer OS） |
| 关键结构 | 六相状态机（Init→Plan→Act→Observe→Reflect→Done），每周期一次 LLM 调用 |

### 1.2 为什么会开这两个总包

2026-09-01 的用户盲测暴露了 **80% 失败率**，且失败模式高度一致（"继续跑吧"类输入后 give_up、用户"不知道发生了什么、需要猜结果"）。于是开两条线：

| 总包 | 回答的问题 | 性质 |
|---|---|---|
| **P4-REVALIDATION-01** | 失败到底怎么发生的？根因是什么？修了有没有用？ | **验证与取证**（可证伪实验优先） |
| **P5-FOUNDATION-01** | 地基缺什么（崩溃安全/对抗安全）？补齐它 | **加固施工**（动代码） |
