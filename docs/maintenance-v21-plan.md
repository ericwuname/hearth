## §5 v21 之后：真·维护期

```
季度体检（全量）：
  每年 1/4/7/10 月第一周：deepseek 20×2 + 应力 24 次 + 回放 31 条
  红线：< 85% 或 应力 > 0 panic → 触发问题分析

按需增量：
  新功能 → 1+ 基准任务 + wiring 断言
  修 bug → 受影响题 + 回放 + 应力受影响的场景
  模型升级 → 全量基准（新模型跑一次基线）

不跑：
  经验实验、embedding 对比、LLM 精炼、正交变量矩阵
  ——这些是锻造期的方法，不是维护期的日常
```
