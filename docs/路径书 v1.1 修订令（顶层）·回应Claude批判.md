## 一、当场认错（三项，不辩护）

### 1.1 墙头草模式——成立，这是最痛的一条

文档 19（决胜局，18:50）与文档 20（转向路径书，19:05）**相隔 15 分钟**，中间没有出现任何新证据——唯一的新输入是用户的一句话。15 分钟前我亲手设计了"可证伪、低成本、不辩论"的决胜局，15 分钟后把它取消了。**这正是我们自己登记过的"犹豫 → 方向立马就变"模式，发生在全项目最贵的一次决策上。**

正确的做法本应是：把用户的话（通用能力必须是成熟可交付产品）作为**新约束输入**，检查它与既有决策的兼容性——事实上兼容（决胜局正是"能不能低成本补上通用能力缺口"的验证实验），然后做决策论辩护或修正，而不是整份推翻重写。

**治理条款（即刻生效）**：此后任何重大方向决策文档必须①引用其所依据的证据编号；②新输入只允许更新受影响的分支，禁止整份推翻；③收到用户挑战时，先产出"决策论辩护或修正分析"（说明哪些结论受新输入影响、哪些不受），再改文档。**用户挑战不是推翻前决策的自动授权，是要求重新论证的指令。**

### 1.2 "更便宜"账算错了——成立

文档 20 自称比决胜局便宜，但自家时间线写着 D+7~14 才到 MVP，而决胜局"几天级"。Step 4 的局部说法（"不改代码的对照实验比修 B3 便宜"）成立，但整体方案的比较基数错了。数字矛盾任何人拿计算器都能核对出来——这类低级错误不该出现在顶层文档。

### 1.3 抽验纪律缺口——我的抽验复核了数字，没复核口径

Claude 源码验证发现两处与顶层抽验表不符：

| 项 | 顶层抽验 | Claude 复核 | 顶层重测裁决 |
|---|---|---|---|
| AgentLoop 字段数 | 61（标 ✅精确） | 63 | **61**（两种 grep 口径一致）；63 疑为 struct 边界口径差——**分歧记录在案，不伤结论** |

## 二、RC1 教训注释：本轮最有价值的发现，采纳并修正叙事

### 2.1 实测确认

`loop.rs:4093-4095` 注释原文：

> "W3 (D3=C): run 级粗粒度完成置位——生产者是**事实校验**（本方法仅在 Done 相位 verify 通过后调用），非 LLM 自报（**RC1 教训**）。"

总账 ledger-v3 RC1 行：*活性信号接线断裂（长程必死 ~15 步）……生产者 = Done 相位 verify 通过，非 LLM 自报*。

### 2.2 这改变了什么

**"完成判定权归还模型"（终审报告/路径书的叙事）是错的或不完整的**。"不让模型自报完成"不是一时疏忽，是踩过真坑（长程 15 步必死）换来的护栏。正确叙事：

- **死锁的死因 ≠ "有事实校验"**，而是 **"问答类任务没有一条对应的事实校验路径，永远碰不到完成置位点"**（节点完成唯一生产者在 Done 相位 verify 后，纯问答任务走不到那里）；
- **解法 = 给问答类任务补一条事实校验路径（B3 + 配套信号）——这是把"必须有事实、不能靠自报"的 RC1 原则延伸覆盖到漏掉的场景，是加固，不是推翻**；
- "竞品让模型宣告完成"的准确解读也修正：竞品是在 **checkpoint/diff/验证文化**的框架里让模型宣告——宣告 + 用户可验证，不是裸自报。Hearth 的 RC1 教训与竞品范式**不矛盾**，矛盾的是把"事实校验"窄化成了"只认写盘"。

### 2.3 对两个 1 的影响

- **第二个 1 的价值上升**：判断层（诚实标注/验证文化/结论自标注）恰恰是"RC1 原则 + 模型驱动"的正确合成——这块是我们的真差异化，无论宿主是谁都要做，且**不能省略验证环节直接抄"模型自报"**；
- **W1 设计小样必须重写相关章节**：把"归还判定权"改为"判定权分层——模型驱动节奏、事实校验守门、问答路径补全覆盖"；
- **批判报告 §12 的"知识迁移"三条原样成立**（它自己写的就是"完成判定权必须属于模型、框架只留护栏"——严格说这条也要按 RC1 修正为"完成判定 = 模型驱动 + 事实校验守门"）。
