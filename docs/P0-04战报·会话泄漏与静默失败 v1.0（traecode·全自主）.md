## 一、修复 1 · 会话无界泄漏（**高 · DoS**）

**位置**：`crates/agent-runtime/src/session.rs`（`cleanup_finished`）

```rust
match s.finished_at {
    Some(t) => { /* 按 TTL 回收 */ }
    // Active: always keep.
    None => true,          // ← 洞在这里
}
```

**机制**：回收**确实接线了**（`service/main.rs:599` → `start_cleanup_task`，TTL 3600s / 扫 300s），
但它以 `finished_at.is_none()` 判定"活跃"——而**从未 `send_message` 的会话 `finished_at` 恒为 `None`**
→ 落入 `None => true` → **永不回收**。

**后果**：
- 内存里的 `sessions` map **无界增长**；
- 每个会话在创建时还建了 `sessions/{uuid}` **工作区目录**（`create_dir_all`），同样永不清理；
- 触发成本极低：反复 `POST /api/v1/sessions` 且**从不 `send_message`** 即可。

**修复**：
1. `Session` 新增 `created_at`（此前**没有创建时刻**，无法判断新旧——这正是洞能成立的原因）；
2. `None` 分支改为：`!running && now.duration_since(created_at) > ttl` 时回收，
   并同步清理工作区目录；
3. **`running == true`（真的在跑）仍然永不触碰**——不改变既有安全语义。

**回归测试**：`test_v12_cleanup_finished_evicts_only_expired` 已重写为覆盖四类会话
（idle / running / finished / 宽 TTL 保留），断言**修复点**："从未启动的会话必须被回收
（修复前此处恒为 `Some` → 无界增长）"。

## 二、修复 2 · webhook 静默失败（"不静默"原则）

**位置**：`crates/service/src/webhook.rs`

```rust
let _ = tokio::time::timeout(std::time::Duration::from_secs(5), cmd).await;
```

`let _ =` 把三类失败**全部吞掉**：`curl` 不存在（Windows 默认无 curl）、5s 超时、非零退出。
**注册端拿不到任何失败信号**——告警/回调永不送达却**零痕迹**。

**修复**：保持 fire-and-forget 语义，但四路分支分别留痕
（成功 `debug` / 非零退出 `warn` + stderr / spawn 失败 `warn` / 超时 `warn`）。

## 三、修复 3 · `spawn_open` 误报"已打开"

`cmd.spawn()` 成功即返回 `"opened: {target}"`，但 **spawn 成功 ≠ 打开成功**
（headless Linux 上 `xdg-open` 常立即非零退出）。已改为如实措辞：
`"opened: {target} (仅表示已请求外部程序处理，不代表打开成功)"`。

## 六、方法论：这条主线已经非常清楚

连续四张卡抓到的缺陷，**绝大多数是同一句话的不同变体**：

> **"代码假设了某个东西存在/成立，而它在另一种平台、另一种配置、或另一种调用方式下并不成立。"**

| 卡 | 被假设的东西 | 实际 |
|---|---|---|
| P0-01 | `is_absolute()` 能识别绝对路径 | Windows 上不能 |
| P0-02 | 用户输入不会被当命令行选项 | 会（`--pre`） |
| P0-02 | 初始 URL 通过白名单就够了 | 重定向可绕过 |
| P0-03 | landlock 会兜底越权写 | 只在 Linux 存在 |
| **P0-04** | `finished_at.is_none()` ⇒ 会话是"活跃"的 | 从未启动的会话**恒**为 `None` |
| **P0-04** | 注释里写的防护层真的存在 | A1：代理 env **不存在**；A2：成立 |

**建议固化为检查项**（未实施）：
1. **凡断言"活跃/已启用/受保护"，都要问"还有没有别的原因能产生同一状态"**
   （`None` 既可能"在跑"也可能"从没跑过"——**状态语义不可反推**）；
2. **凡注释声称依赖某机制，必须能指到那一行代码**；
3. **凡"静默吞错"，必须有留痕**。
