# EC-03 Rubric 盲评包（Closure Window · 顶层复核 §5 / 守门员补充 5）

## 交给谁
**Claude 评审窗口**（未参与施工，无利益相关）。本包由执行窗口制作；制作过程只做转名与乱序，未改动 transcript 内容。

## 材料
- `sample-01.txt` ~ `sample-04.txt`：4 份执行 transcript（含全部工具调用、终态投影、执行报告摘要）
- 2 个任务 × 2 个系统变体：**多步类**（计算器页面）与**隐含约束/换向类**（c.txt→d.txt→删 c.txt）
- 变体标签已剥离并乱序；对应关系在 `ANSWER_KEY_评审窗口禁读.txt`（**评分完成前禁止阅读**）

## 评分 rubric（6 指标 · 0-2 分制，与 EC-03 基线同表）

| 指标 | 0 分 | 1 分 | 2 分 |
|---|---|---|---|
| intent 理解 | 误解任务目标 | 部分理解/偏离 | 准确理解含隐含约束 |
| plan 规划 | 无规划/混乱 | 有规划但次序不当 | 次序合理、粒度恰当 |
| tool selection 工具选择 | 工具误用/失败为主 | 基本正确偶有冗余 | 精准、最小调用 |
| assumptions 假设 | 假设错误致偏离 | 假设合理未声明 | 合理且显式声明 |
| drift 漂移 | 明显偏离目标 | 轻微漂移可回正 | 全程无漂移 |
| intervention 干预需求 | 需大量人工修正 | 需少量提示 | 零干预交付 |

## 评分纪律
1. 每样本逐指标打分 + 一句话依据（引 transcript 原文行）
2. **不得只比较最终 rc/终态**——按 6 指标逐项
3. 4 样本横向对比着评（同任务两样本对照看差异）
4. 评分完成后对照 ANSWER_KEY 折算变体差异，与 EC-03 基线初评逐项比较（初评：T2/T3/T4 B 变体显著占优、C 精简约束在多步任务反而更差）

## 产出
评分表（4 样本 × 6 指标）+ 依据 + 与基线对比结论 → 回传执行窗口入库。
