## 一、诚实回答：开卷考试为什么考砸了

三句话，全部有实证：

1. **抄作业抄错了层**。对标抄的是显性功能清单（21 个子命令、安全矩阵、486 测试），没抄隐性交互范式（模型驱动、每结果即回模型、**完成由模型宣告**）。深挖报告的 10/10 回代证明：80% 失败率来自"框架替模型做完成判定"——而这一条恰恰是所有竞品的默认行为，是可以直接抄的。
2. **四次局部正确的补丁强化了错误范式**。R1→v20 gate→v22 gate→修 B（revision 收口），每次都"对"，每次都把判定权从模型手里拿得更死（深挖报告 §5 实证）。
3. **治理奖励了错误的东西**。近 30 天文档提交是代码的 2.26 倍；497 个测试 0 条用户行为断言。流程在产出"关于失败的文字"，没有产出"阻止失败的测试"。

**结论：考砸不是智力问题，是抄错答案 + 激励错向。两者都真实存在——但修复位置不在 Hearth 本体，在路线选择。**

## 二、1+1>2 的施工图：两个 1 的宿主分离

Hearth 的结构性错误是**试图在自制地基上同时建两个 1**：既造通用 harness（第一个 1），又在其上做认知治理（第二个 1）——结果地基 80% 塌陷，上层无从谈起。

**转向后**：

```
第二个 1（自己的）：宪法治理 · 判断层研究 · 技能库 · UNVERIFIED 诚实标注 · SeedLM/内部桥愿景
                    ↓ 建在（MCP / extensions / hooks / system prompt 层）
第一个 1（别人的）：成熟开源底座——模型驱动 · 流式 · diff · 可回退 · 纠偏 · 分级自治 · MCP 标准接入
```

- 第一个 1 由大厂/基金会维护，**不再是我们 failures 的承载体**；
- 第二个 1 是真正差异化的部分——它本来就是模型无关的，**换宿主零损失**；
- Hearth 两个月里真正值钱的产出（教训与范式）全部可以带走（§四清单）。

## 三、主路径：Extend 四步

### Step 1 · 底座对照实验（1-2 天，选型实测二合一）

装 **Codex CLI / Goose / OpenCode** 三个底座，配置 Agnes（OpenAI 兼容端点）与 Ollama，**跑同一份 A 组 10 条盲测**（replay41 逐字，全新 session）：

- **这是对照实验**：成熟底座的成功率若大幅领先 8%，三层死锁根因模型被反向验证；
- **这也是选型实测**：判据 = ①A 组成功率 ②中文体验 ③接 Agnes/Ollama 的摩擦 ④扩展机制成熟度（MCP/extensions）⑤代码可读性（Rust 优先）。

### Step 2 · 底座定版（D+3~5）

按 Step 1 数据定底座。Codex CLI（Rust/Apache-2.0/沙箱同款/团队技能匹配）与 Goose（Rust/Apache-2.0/Linux 基金会/15+ provider/local-first 对口弱模型战略）为双热门。

### Step 3 · 第二个 1 的 MVP（D+7~14）

把宪法治理（八条注入）、UNVERIFIED 诚实标注、技能库、判断层观测（校准数据采集）以 **MCP server / extension** 形式接入底座，跑通中文 + 弱模型场景验收。

### Step 4 · 决胜局的改写（双向实验，比原门禁更便宜）

原决胜局（在 Hearth 上修 B3+配套 → G-1）**改写为**：**底座 vs Hearth 的 A 组对照**。

- **底座大幅领先** → 三层死锁模型验证 + "通用能力是地基"论点同时坐实 → 主路径确认，Hearth 本体按 §五收尾；
- **底座也跑不好**（中文/弱模型场景翻车）→ **Hearth 的存在性论证反而被证成**（市场对中文+弱模型+自托管场景确有空白）→ 此时"继续自研"才第一次拿到正当性，且带着三层死锁的精确修复点（B1/B2/B3）回归主线路径；
- **无论哪个结果都不再是自嗨**——这才是把批判报告的 §13 可证伪条件用到极致。

## 五、Hearth 本体收尾方案

1. **Node 15 冻结流程降级**：campaign ≥30 runs **取消**（转向后其增量数据价值不再覆盖成本）；已有数据链（A/B 正式轮、Phase D、矩阵、三报告）整理进归档包；冻结 CANDIDATE 改标 **v0.2.23-final（归档版）**；
2. **归档仪式**：git tag + git archive 日期戳备份存 Desktop（既有惯例）；
3. **知识迁移卡**一份：护栏范式 / 完成判定权归模型 / 三层死锁 / 代理指标陷阱 / 激励结构——五张卡，每张 ≤10 行；
4. **砺收尾任务**：对三份外部报告的独立判读意见（学术价值保留，其中对批判报告三条主论证的评审对 Step 1 对照实验设计有直接输入）；
5. **B3+配套施工取消**：由 Step 4 对照实验替代（更便宜、更有说服力）；
6. P5-FOUNDATION-01 段 2 **取消**（不再加固即将归档的地基）。
