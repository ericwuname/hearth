## 3. 对补跑"零删失"推断的评价（方向对，效力有限）

附页 §二(c) 末尾写道：补跑 3 条零删失且 2/3 完成 → "说明 v5 的 2/3 不是靠剔除无效样本抬出来的"。

**方向正确，但推不到那么远**，两条理由：

1. **补跑零删失只能证明"这一批没被剔除污染"**，不能回溯验证 v5 的 A 臂——因为 **v5 的 A 臂本来就是 3/3 有效，批次内压根没发生过 A 臂剔除**；
2. 被剔除的 **#29 与 PRE#27 属于追问类，不是 A 臂**。

### 顺带更正我自己 v3 的一处不精确

我 v3 §1(c) 写的是「本批剔除了 #29（post 侧）与 PRE#27（基线侧）……本批 A 臂从'1/3 含 2 个无终态'变成'2/3 全部有效'」——**这里把追问类的剔除与 A 臂的读数变化混在了一句里**。

**准确的 (c) 应是**：A 臂在 v5 批次内 **3/3 有效、无批内剔除**；真正的动作是 v5 之前那批（1/3，含 2 个无终态）被**整体作废替换**。**作废是正确且必须的**（那批确属仪器失败），但"作废 + 重跑"使 pre/post 时间趋势不可比——这才是 (c) 对 A 臂的真实含义。

**建议附页 (c) 按此更正**，避免把追问类的剔除记到 A 臂头上。

## 4. n=6 之后，"零余量"改变了吗？没有。

| 批次 | 读数 | 与阈值（66.7%）的关系 |
|---|---|---|
| v5（n=3） | 2/3 = 66.7% | **等于**阈值 |
| 补跑（n=3） | 2/3 = 66.7% | **等于**阈值 |
| 合并（n=6） | 4/6 = 66.7% | **等于**阈值 |

**补跑增加了样本，但没有增加余量**——限制 (a) 的性质未变，任何单个样本翻转仍会跌破阈值。

**但有一个真实的正面收获值得写进去**：两批**独立**跑批都得到 66.7%，**重复性（reproducibility）比区间收窄更有说服力**。Wilson 95%CI 从 n=3 的约 21%–94% 收窄到 n=6 的约 30%–90%（仍很宽），但"两批独立一致"这一条是 n=3 时完全没有的证据。

**建议附页 (a) 补一句**：「(a) 的零余量**未因补跑而改变**；补跑的真实价值是提供了两批独立一致（均 66.7%）的重复性证据，而非收窄区间。」
