## 3. 🔴 撤回 L1-b 立项（v1 的有条件同意作废）

### 为什么撤回

v1 我给"有条件同意"的**经验前提**是「零交换样本 2/2 全败」。执行窗 14:35 自我更正：**#28/#29 是采集失败（无终态、日志~650 字符），不是实验失败**——且它们的"0 工具交换"读数同样来自被截断的日志，**不可信**。

即：**目前没有任何一个有效观测证明"零交换的追问任务真实存在并失败"。** 经验前提归零。

### 保留什么

源码层面的事实**依然成立**：`loop.rs:2168` 守卫是 `tool_exchanges_this_run >= 1`，零交换样本**在源码上被确定性排除**。这是源码事实，不依赖样本。

但"该情形在真实追问任务中**是否发生、占比多少**"——**目前无有效数据**。这决定了 L1-b 的价值大小，不能靠源码推测。

### 裁定

**L1-b 暂不立项。** 前置：
1. #28/#29/#30/#32 用 v4 仪器重跑，拿到**有效**的零交换/有交换分布；
2. #21 归因落定（§1）；
3. 若确有零交换追问且失败，再立项。

### 立项时的硬性设计约束（预先写下，避免届时放松）

回执与顶层 §四 的表述是「**模型已输出非空文字回答**」入救回条件——**这个定义不能用**，两条理由：

1. **与 RC1 直接冲突**：RC1 刚立"完成置位 = 事实校验，非 LLM 自报"（`loop.rs:4134`）。"非空文字"就是**纯 LLM 自报**，等于把刚关上的门再打开；
2. **会救活空转**：`:2183` 日志原文写着护栏意图 —— *"LLM idle-spin must not be rescued"*。模型边 replan 边吐"让我再想想…"同样满足"非空文字"，**假完成当场复活**。

**建议形态**：`文本 ≥ 阈值 ∧ 不含空转标记 ∧ 非"仅重述计划" ∧ consecutive_errors == 0 → Done`，**仍打 UNVERIFIED**；**反空转护栏保留**（零交换且无实质回答 → 维持 give_up）。

## 4. D2 合取判定：悬置（SUSPENDED），不得字面记"有缺口"

顶层已授权砺判定。数据现状：

| 条件 | 规则 | 实测 | 有效性 |
|---|---|---|---|
| B 臂 ≥3/5 | ✅ | 4/5 | ✅ 有效 |
| A 臂 ≥2/3 | ❌ | 1/3 | ⛔ **含 2 个无终态无效样本**（A1 两轮均无终态，有效仅 A2 failed / A3 completed） |

### 裁定

**D2 悬置。既不记"根因模型验证成立"，也不记"根因模型有缺口"。**

理由：**A 臂 1/3 的分母里装的是仪器失败，不是实验失败。** 把"无终态"计为 failed，就是本次 #28/#29 刚犯、并被正确作废的那个错误——**同一个错误不允许在同一天犯第三次**。

- 有效样本实际为 2（A2 failed、A3 completed）→ 1/2 = 50%，仍 < 2/3，但 **n=2 且仪器刚修，无判定力**；
- A1 两轮无终态属 driver `wait_terminal` 在短轮（无工具调用）上提前退出——**仪器缺陷，非代码回归**。

### 处置

1. A 臂用 **v4 轮询式驱动**重跑，须 ≥3 条**有终态**的有效样本；
2. 重跑后由砺按 D2 规则出具**一页判定**；
3. 在此之前，D2 状态一律写 **SUSPENDED**，引用本裁定。

## 5. 系统性观察：同一错误类已第三次出现（值得单独登记）

| 次 | 事件 | 性质 |
|---|---|---|
| 1 | B1 判定器 give_up 主导性误判（provider_fail 字符串优先于终态） | 判定器缺陷被读作实验失败 |
| 2 | 追问类 #28/#29"零交换全败" | **采集失败被读作实验失败**（v1 已作废） |
| 3 | A 臂 1/3 | **无终态样本被计入分母**（本裁定拦下） |

**共同模式**：**把仪器/判定器的失败，读成被测对象的失败。**

这正是 Claude Q6 那条建议的价值所在，也印证了本项目的既有纪律——**"无终态"必须被机器显式判为无效并中止该条件，而不是由人去解释**。建议把这条固化为 driver/判定器的**硬断言**（无终态 → 该样本不计入分母 + 该条件直接判 INSTRUMENT_INVALID），与 R-1 的空 uuid assert 同款。

> 执行窗这次**主动作废 v1 读数**，是这个模式第一次在**产生结论之前**被拦住——值得记一笔正面。
