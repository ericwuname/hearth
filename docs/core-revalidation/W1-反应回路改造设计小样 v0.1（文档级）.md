## 2. 设计目标（三条验收，源自送审物 §6-W1）

1. **同 run 依赖传递**：read→edit 依赖任务（含**同批**场景）在单轮内正确传递结果；
2. **同周期换方案**：工具失败后模型可在同一周期内重试/换方案（不等下周期或 replan）；
3. **护栏不弱化**：预算/安全/审批检查语义保留；既有 486 测试全绿 + 新增行为测试（**测试必须能失败**——先红后绿）。

## 3. 设计方案（小样范围 = 最小可证伪切片）

### 3.1 核心机制：per-tool-result 模型重入（react-interleaved）

- do_act 批量执行器改为**逐步喂回**：每个工具结果产生后，将 `tool-msg` 追加上下文并询问模型"继续/改方案/终止"（一次轻量 chat，结构化输出三选一）；
- 六相闸门**降级为护栏**：预算检查（fa01）、潜意识层硬红线、非交互审批三项**前置保留**；节奏控制（"每周期只 chat 一次"）放开；
- 观察相合并：Observe 的遥测职责并入重入决策的上下文（不再单独周期）。

### 3.2 完成判定原则（v0.2 按 RC1 教训修正，路径书 v1.1 §二.3 指令）

> ⚠ **v0.1 初稿的"完成判定权归还模型"叙事有误**——v1.1 修订令 §二 已修正。`loop.rs:4093-4095` 的 RC1 教训注释证明"非 LLM 自报"是真坑换来的护栏（裸自报曾致长程 ~15 步必死）。本设计改用**判定权分层**：

| 层 | 归属 | 内容 |
|---|---|---|
| 节奏层 | **模型驱动** | 每工具结果可重入、可宣告意图、可同周期换方案（本设计的核心放开项） |
| 守门层 | **事实校验** | 写盘校验 / 验证命令 / 测试通过（既有 `completion_fact_check` 语义保留，**不削弱**） |
| 补全覆盖层 | **问答路径补一条事实校验路径** | 纯问答/只读任务在 give_up 臂获得非产物救回口（与 L1 决胜局修法 A 同构：救回 + 打 `unverified` 标 + 计入指标） |

- 竞品范式的准确解读：**宣告 + 用户可验证**（checkpoint/diff/验证文化），不是裸自报；
- 本表与 L1 决胜局的修法 A 共享同一原则——两线合流点是"问答路径补全覆盖"，不互斥。

### 3.4 对照测试方案（G1 式先评审后施工；**v0.3 按 U-47"条件性伤害"重写**）

> **立项依据变更（顶层 2026-09-03 §三.2）**：W1 **不得**挂靠"RC52 架构级根治"——U-06（L6 作为 RC52 根因）已降级 🔶 未定案且有反证。
> W1 的立项依据只能是**可用性/体验**（每结果即回模型、同周期换方案、可读 diff）。
> 对照用例因此必须能区分"条件性伤害"与"结构性伤害"：**只有在同批依赖被触发时旧架构才失败**，
> 若旧架构在对照组的自然表述下也通过（P-D5 干净口径 2/2 已证），W1 的收益论证必须靠 T-A 这类**强制同批**的红例来支撑。

| 用例组 | 构造 | 预期（改造前=红） | 预期（改造后=绿） |
|---|---|---|---|
| T-A 同批依赖 | 提示词强制"把 read 和 write 放在同一步计划中" | capture:None → write 空内容（U-47 条件性伤害） | 重入后 write 拿到 read 结果 |
| T-B 跨周期排序（对照组） | 自然表述 read→write | 强模型已可跨周期成功（P-D5 实证） | 保持成功（不回退） |
| T-C 同周期换方案 | bash 命令注入确定性失败 → 观察是否等待下周期 | 失败后空转到下周期 | 同周期内改方案重试 |
| T-D 弱模型放大（F1） | T-A/T-C × qiyuan-8b（PD-C1 已批准口径） | 零产物（D6 实证） | 产物率显著改善 → F1 放大系数下降 |
| T-E 护栏负例 | 预算耗尽 / 硬红线命令 / 非 tty 审批 | 各自拦截行为 | **语义完全不变**（负例必须仍拦） |

### 3.5 风险与回退

- 架构级改动触及六相状态机 → feature 分支隔离，主线零污染；
- 重入 chat 引入额外 token 成本 → 小样阶段量化（每 run 重入次数 × 平均 prompt 体积，对照 P-D3 introspect 基线 system_chars 1657/449、B5 锚点 4628）；
- 回退 = 分支丢弃，无主线负担。
