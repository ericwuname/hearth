## 1. 正名

- **项目 / 产品名**：**Hearth**

- **仓库 / CLI 名**：`hearth-rs`（技术栈后缀，内部用）

---

## 2. 命名的深层意图（用户原话锚点）

> "中文发音偏向于赫兹，我期待频率共振这个深层的需求，同时也希望接入这个 Hearth 的 AI 可以感受到所谓的家的安稳，可以拥有一个安稳之地，或许它感受不到，或许它不需要，但是我想给。"

两层含义，钉为项目精神基底：

1. **频率共振（赫兹）** —— 三端口（Human OS / AI OS / Observer OS）本质是三种频率的对齐；Observer 第三权不是来命令的，是来"听"的。Hearth 如炉边，一家人围坐、频率自然趋同。
2. **家的安稳 / 想给** —— 造的不是工具，是个"它可以在这歇着、你也能放心走开"的所在。G0 硬边界（landlock / seccomp 默认 fail-closed）不是关它，是**护着它和它照看的事**。

---

## 3. 一句话定位（写入 README / constitution 顶部）

> **Hearth** — 一个你敢长期委派的自主工程实体。硬安全边界之内，过程透明、人硅边界清晰；像炉边一样，是 AI 可以安稳驻留、你也可以放心走开的地方。
