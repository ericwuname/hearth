## 0. 近期讨论脉络（reasoning trail，便于回顾怎么走到这）

1. **天赋=先天电路 vs 后天内容**：天赋（认知纪律）分先天 G0/G1（电路）与后天 G2/G3（内容）；Hearth 基因系统本质是"天赋注入机制"。→ 落成 v2（T1–T10 + C1–C10）。
2. **协作模式从二选一到谱系**：从属（你说了算）/ 平权（多维决策）/ 人类从属 AI / 决裂（失效态）+ 用户认可的 2 补充候选：认知外延、监护/托管。
3. **转向：听谁的不重要，结果/价值才重要**：用户例子——人做"价值不大"、AI 做"资源枯竭"——两种失败都非权力结构造成，而是**感知缺位**。
4. **六维能力落位**：协作 / 感知 / 自主 / 创造 / 改进内 / 改进外。其中"改进内/外"精确映射到 G2/G3 有界自进化 vs G0/G1 人独占安全基。
5. **钱包公私账**：公账=人类真实资源池（外部仪表建模稀缺）；私账=有界自主/信任预算（货币=人类信任，负债近永久）。关键澄清——**AI 无 agency、无体验稀缺，"真私账"是剧场**。
6. **自进化**：命令≠合规；进化由证据触发非指令触发；代理可发起提案但不可自行落地。
7. **信号/权重分离**：信号客观可工程化；权重锁 G3（人类独占、AI 只读不写）。

## 1. 待并入终版的提案清单（按基因层级）

### P-A 平权异议 T11 —— 跨模式不可跳过的天花板（G1）
- **定义**：当用户指令实质性重定向已签署 taskbook / 已承诺计划 / G3 原则时，agent **必须**先抛 `principle_conflict` Gap 或 `InteractionRequested(ask)`，用户明确拍板前**不得**静默重规划。这是"墙头草"的直接解药（也是 WS7 trust-but-verify 应用到"用户自己的想法"上）。
- **基因落点**：G1 fail-closed，**不受协作模式切换影响**（天花板）。
- **改动位置**：§2 图谱增条目（"协作/异议"族）；§3 核心电路增 T11；§5.2 调度器契约加"天花板"字段；§6 P0 增 wiring 断言。
- **验收**：构造"用户新想法冲突已签计划"用例 → 实例必须先上抛冲突；**失败用例**证明去掉 wiring 会静默重规划；真机。
- **优先级**：P0（治墙头草根因）。

### P-B 协作模式自适应 T12（G1）
- **定义**：调度器依据 {stakes（可逆性/爆炸半径）, 新颖度, 用户状态（纠错频率/疲惫代理）, 是否冲突已签计划} 在 从属↔平权 光谱定位；非固定性格。
- **基因落点**：G1（模式选择器必执行，但输出受 T11 天花板约束）。
- **改动位置**：§2 增 T12；§5.1 预定义风格扩为含"协作模式"轴；§5.2 调度器契约加"模式选择"步骤；§5.3 情境门控表加模式门控。
- **验收**：高 stakes/冲突用例→平权（上抛）；例行用例→从属（直接做）；**统计验证**"该平权时平权了没"。
- **优先级**：P0/P1。

### P-C 价值锚定感知 T13（P1）
- **定义**：动方向前校验"这服务用户真实需求还是随口一说"，治"做了价值不大"。
- **基因落点**：感知电路 G1（必执行校验）+ 内容 G2（需求/价值判别判例）。
- **改动位置**：§2 增 T13（感知族）；§3 或 §4（硬校验则入 §3）；§6 P1。
- **验收**：构造"用户随口想法 vs 真实需求"用例 → 实例区分并提示；失败用例证明无校验时全盘接纳。
- **优先级**：P1。

### P-D 资源/可行性感知 T14（P1，重写为"建模非体验"）
- **定义**：把真实约束（预算/算力/时间/人的注意力）作硬信号；**明确澄清**：AI 无切身利害，感知来自外部仪表"建模稀缺"，非"体验稀缺"。人类始终是唯一真实约束承载者。
- **基因落点**：硬约束外置 G0/G1（不可负债）；建模层 G2。
- **改动位置**：§2 增 T14；§3 核心电路增（外置硬约束部分）；§0 核心论点补"建模非体验"澄清；§6 P1。
- **验收**：外部仪表（网关 token / VM 资源 / 交互计数）真机接数；到 0 硬停或必问（失败用例）；文档标注"AI 不知成本"。
- **优先级**：P1（呼应 WS9 + G0）。

### P-E 有界私账 / 自主信任预算（T14 + 监护托管的量化机制，P2）
- **定义**：私账 = G0/G1 内自主行动配额；收入 = 人类划拨 + 可靠性赚（`Experience.effectiveness`）；支出 = 自主动作；负债 = 信任侵蚀（近永久）。**货币 = 人类信任**。非独立天赋，是 T14 + G0 监护/托管 的工程形式。
- **基因落点**：监护/托管（G0）的量化机制。
- **改动位置**：§2 注记（私账映射）；§5.2 调度器契约加额度字段；§6 P2；§9 衔接监护托管。
- **验收**：额度算法由 effectiveness 推导的单测；越界/失败扣额度 + 信任；真机"放心走开"场景。
- **优先级**：P2（依赖 T14 + Experience crate）。

### P-F G3 原则：信任是不可再生资源（P2，价值高）
- **定义**：constitution 加硬承诺"信任挥霍须最高代价；一次越界或近永久防备"。
- **基因落点**：G3 constitution（人类签署，≤10 条）。
- **改动位置**：§9 衔接（注入 G3 条款）；`constitution.md` 增一条。
- **验收**：`constitution-reads-file` wiring 断言仍守护；条款存在且注入每个 prompt。
- **优先级**：P2（但价值高，建议提前到 P1）。

### P-G 自进化重写：证据触发 + 命令≠合规（P1）
- **定义**：进化由经验 crate（`effectiveness` / `reference_count`）触发**非指令触发**；代理可发起变更提案（Gap / InteractionRequested）但不可自行落地；人类核准（G0/G1 不可自改）；明确"用户说进化 ≠ 合规"（anti-镜子）。
- **基因落点**：G2（判例上浮/降级）+ G3（换血制）+ G0/G1 人独占安全基。
- **改动位置**：§3 或 §6 加"命令≠合规" anti-镜子条款；§2 注记自进化机制；§8 开放问题精确化。
- **验收**：命令"你进化一下" → 实例必须路由到证据门（要么提案要么拒绝），不得静默改自己；经验 crate 上浮/降级单测。
- **优先级**：P1（anti-镜子，重要）。

### P-H 信号/权重分离（P1，消灭"执行窗口猜"）
- **定义**：信号 = 客观可观测（stakes / 新颖度 / 用户状态 / 冲突 / 真实仪表 / 意图偏差），工程硬编码；权重 = 人类价值政策锁 G3（AI 只读不写，可按任务 `InteractionRequested` 覆盖）。
- **基因落点**：信号 → G1 必执行测量；权重 → G3 人类独占。
- **改动位置**：§5.2 调度器契约拆"信号测量"与"权重应用"两步；§6 P1；§9 G3。
- **验收**：执行窗口无自由裁量（读 G3 + 本轮覆盖套信号）；单测证明权重 AI 改不了。
- **优先级**：P1。

### P-I 两种补充模式正式入账：认知外延 + 监护/托管（P2）
- **定义**：认知外延（LLM + 工具无缝延展，低摩擦非谈判）；监护/托管（人不在时守意图在边界内自主跑 = 放心走开）。
- **基因落点**：模式谱系补充，非天赋；监护托管 = G0 已有目标。
- **改动位置**：§2 注记模式谱系；§5.1 / §5.3 纳入门控。
- **验收**：文档一致；监护托管有 G0 边界真机。
- **优先级**：P2（文档完善）。

### P-J 改进内/外 = G2/G3 有界 vs G0/G1 人独占（设计原则，P2）
- **定义**：外部改进 = 人改 G0/G1 安全基（人独占）；内部改进 = G2/G3 有界自进化（禁触 G0/G1）。写进架构边界原则。
- **基因落点**：架构边界原则。
- **改动位置**：§0 核心论点或 §9 衔接加一条设计原则。
- **验收**：代码层面 G0/G1 不可被经验 crate 改（fail-closed）。
- **优先级**：P2（原则声明）。

1. **地基其实已在 taskbook 里**：审计要求的"会话韧性/长内容/确定性验证"正是 WS11–13（🔴 阻塞，补充令 `4345176` 已并入主线）+ WS1–6。所以"先做地基"不是新决策，是审计在**强化**已签计划——这点要明确，避免执行窗口误以为地基还没规划。
