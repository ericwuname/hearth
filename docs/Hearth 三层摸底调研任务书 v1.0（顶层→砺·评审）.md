## 0. 一句话任务

对项目的三层（骨架层 / 测量层 / 判断层）各回答三问：**现在是什么样子（AS-IS）→ 可以建成什么样子（CAN-BE）→ 理想是什么样子（TO-BE）**，最后给一张"三层 × 三问"总表 + 分桶差距清单。用户原话："我希望知道，当前是什么样子的，可以建成什么样子，理想是什么样子的。"

## 1. 背景（为什么摸）

顶层已裁定：他说的"旁边的东西" = **判断层（校准/元认知）**，并立了 v0.3 认知线种子（E1/E2/E3，见 §4.3）。本任务书把三层现状纵深摸清，作为 v0.3 立项与"认知线"施工的底图。

**与既有文档的关系**：砺的《Hearth 阶段盘点》（2026-08-31）已覆盖全局账目（未做设想 26 项 / 冻结裁决 / v0.3 规划）。**那份盘点过的事实不必重查**，直接引用并标注来源；本任务只补三层纵深处那份没覆盖的部分。

## 2. 三层模型定义（对齐口径）

| 层 | 定义 | 管什么 | 对应人的能力 |
|---|---|---|---|
| **第一层 · 骨架层（发动机）** | 让任务能被执行的结构：PDCA 相位循环 / TaskGraph / Terminal 九态 / 审批门 / 沙箱（landlock+seccomp fail-closed）/ CLI·REPL / 工具调用 | **做事** | 手脚 |
| **第二层 · 测量层（尺子）** | 知道做得怎么样的能力：SimUser（真 PTY driver / 检测器 / metrics）/ 机器审计器（stderr isolation / 截断族扫描）/ 北极星指标 | **知道自己做得怎么样** | 感觉神经 |
| **第三层 · 判断层（认知）** | 对自己的输出做校验与标注的能力：先验证再取信 / 结论自标注（VERIFIED vs INFERRED）/ 代价感 / 独立验证关卡 / 闭环登记的取证纪律 | **知道自己知不知道** | 元认知 |

依赖关系（施工顺序反向）：判断层依赖测量层（没有尺子，"验证"无法自动执行）；测量层依赖骨架层（检测器读的是骨架产出的事实）。**理想态从下往上建：骨架 → 测量 → 判断。**

## 3. 调研要求：三层 × 三问

### 3.1 AS-IS 现状（每层都要）

- 每条结论必须带锚点：`file:line` / 实测数字 / 复现命令，可复算（铁律，不适用任何豁免）。
- 区分三档状态：**有机制（代码+测试+接线证实）** / **有骨架无校验（结构在但判断缺失）** / **零命中（未建）**。
- 骨架层重点：结构可信度剖面——哪些器官有测试护住、哪些是纸面设计；Core Freeze SUSPENDED 下的冻结边界内有什么。
- 测量层重点：SimUser Stage 1 实况（driver/analyzer/metrics/personas/scenarios 五件套 + Node 02 审计器产出）；**28.6% 人工归因口径与 SimUser 口径不可比**这一口径断层要写实；北极星未定。
- 判断层重点：**逐条实锤"未建"**（已知四条见 §4.3，请复核并补全遗漏）。

### 3.2 CAN-BE 可达（每层都要）

- 定义：**以现有骨架为地基、一个施工阶段（v0.3 一轮 + P4 收尾）内**能建成的形态。
- 硬要求：**每条可达项必须给"可失败判据"**（G-2 纪律：没有判据的展望不写）。判据必须是 SimUser 可测 / gate 可跑 / 证据可查的。
- 判断层的可达项请从顶层种子 E1/E2/E3 展开（§4.3），可增补可推翻，推翻需给证据。
- 骨架层可达 = Core Freeze v2 · CONDITIONAL + DG-1/DG-2 落纸后的稳定基线（引用阶段盘点 §2.5，不必重写）。

### 3.3 TO-BE 理想（每层都要）

- 唯一参照物：`constitution.md` 六条宪法 + 用户 v10.0 愿景（内部桥 / 对等协作 / 桌面版 / 连续存在）。
- 每条理想必须标注**对应哪条宪法原则**，以及"现在离它差几层"（差机制 / 工尺 / 差地基）。
- 判断层理想态参考画像：一个跑了 100 轮的会话里，Hearth 每条关键结论自带验证状态；发现问题时登记的是带复现命令的证据包而非感受；对昂贵操作（全量构建/长测试）有代价预估；被独立验证关卡推翻时自动降级自己的置信度。
