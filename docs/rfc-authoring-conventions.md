本约定与 `docs/gene-expression-system-design.md`（以下简称《基因图纸》）互为配套：本约定管"怎么写 RFC 不写错"，《基因图纸》管"规则该落在哪一层、怎么有牙齿"。**两者都读，缺一不可。**

## §1 制度语汇：G0–G3 真实定义（权威，必读）

出处：`docs/gene-expression-system-design.md:28-31`（v12.1 确立，至今未改）。**任何 RFC 使用 G0/G1/G2/G3 字样时，必须与此表一致；不一致的，一律按本表裁定。**

| 层 | 真实名称 | 约束强度 | 表达器官（身体侧） | 硬上限 |
|---|---|---|---|---|
| **G0** | 结构基因 | **物理不可能违反** | sandbox（landlock/seccomp）、审批门、CLI 进程隔离 | 无上限，但每条 = 拓扑级改动，极少新增 |
| **G1** | 反射基因 | 代码分支必然执行 | 相位钩子（subconscious gate / nervous query / CostGuard / 交付三门） | **每条必须挂 wiring 接线断言** |
| **G2** | 检索基因 | 正确时机出现在眼前 | `experience` crate（判例卡 + 情境召回 + 自动注入 prompt） | 无上限，受 KPI 淘汰 |
| **G3** | 叙事基因 | **无牙齿（只做偏置）** | `constitution.md` → `build_messages` 注入 | **≤10 条，永不放宽** |

**三条铁律（全写在这份图纸里，不在任何简报表格里）：**

- **入籍铁律**（`:37`）：每条基因入籍必须声明三元组 **（层级，表达器官，验证方式）**。G1 缺接线断言 → 自动拒绝入籍；G2 缺判例卡格式 → 退回；G3 超 10 条 → 退回。
- **单向上升，不许空降**（`:70`）：新教训一律先入 G2 判例（成本≈0）→ 召回命中率证明价值后升 G1 → 极端重要才进 G0。防止每次事故都冲动立法。
- **G3 换血制**（`:76`）：想加第 11 条，必须先废一条。修宪是大事，默认答案是"不"。

**判别式（写 RFC 时自问）**：一条规则属于哪层，问一句"**违反它的那一刻，会发生什么？**"
- 什么都不发生 → 它现在是栏杆。要么下沉到 G1/G0 给它装牙，要么承认它是 G3 价值偏置（占 10 席之一），要么降为文化文档。
- 报错 / 相位拒绝 / 审批弹窗 → 已有牙，登记它的表达器官和断言测试即可。

**❗ 本轮三份文档踩的坑（写 RFC 时对照自检）：**
- 宪法 = **G3**，不是 G2。RFC-004 把"宪法条款"标成"G2 初始种子"是错层。
- `agent-core` 里的一个 Rust `struct` 最多是 **G1**，不可能是 G0。RFC-005 的"G0 冷却期 = 编译期锁死"是**假 G0**。
- CN-001 想"约束 G2"的元规范，真实 G3 只有 10 席——住 G3 就要走换血制。结论：CN 类文档升为独立 **CN 层（元规范，零强制力）**，不占 G3 席。

## §4 RFC 模板（强制栏位）

任何 RFC 必须包含以下栏位，缺栏退回补写。

```markdown
# RFC-XXX <标题> v<版本>

- 作者 / 日期
- 基线 commit：<git rev + tag，如 fd5829e v17.0>   # 必填，见 H7
- 一句话问题陈述
- 问题来源（真实事故 / 需求 / 推演，禁止"无支撑冲动立法"）

## 层级与入籍（必填，见 §1 入籍铁律）
| 提出的每一条约束 | 声称层级 G0/G1/G2/G3 | 表达器官 | 验证方式 |
|---|---|---|---|
| ... | ... | ... | ... |
# 判定：违反它的那一刻会发生什么？无牙 → 要么下沉装牙，要么承认 G3 偏置（占席），要么降文化文档

## 机制设计
- 落点代码路径（具体到文件:行 / 相位钩子，见 H6）
- 断言落点：docs/xray/wiring-v13.toml   # 必填，禁止新建 vNN.toml（见 H1）

## 自审（必填，见 §5）
- [ ] 假 G0 检查
- [ ] 可达性检查（门的函数有真实调用者吗）
- [ ] 循环论证检查
- [ ] 可序列化检查（若声称重启后恢复）

## 验收判据（可测量，禁"保证想全"类不可证伪表述）
```

## §5 机制设计审查清单（避免四类致命缺陷）

写机制类 RFC 时，逐条过：

1. **假 G0 检查**：声称"G0 / 不可绕过 / 编译期锁死"的机制，真的是物理不可能违反吗？`agent-core` 内的 Rust struct、闭包、延迟计时器——这些最多是 **G1**。真 G0 只有 sandbox/landlock/seccomp、审批门、进程隔离。**落在 agent-core 里的"不可绕过"一律降级为 G1 并挂 wiring 断言。**
2. **可达性检查（门的是没人调用的函数）**：你设计的"拦截点"对应代码里哪一次**真实函数调用**？如果"推翻一个架构决策"在代码里找不到对应的 `execute()` / 工具调用 / syscall，那你的拦截器门的是一个**没人调用的函数**，真实新增覆盖率≈0。先回答"对应哪一次函数调用"再决定机制。**（RFC-005 核心阻塞项）**
3. **循环论证检查**：根因说"LLM 没有 X 能力"，解法却让 LLM 自己做 X（例如"用内省能力列出自己遗漏的因素"）。这是用缺失的能力修补自身。承诺口径从"保证想全"降为"提高覆盖率"，验收改可测量。
4. **可序列化检查**：若声称"进程重启后状态恢复"，机制不能是 `impl FnOnce` 闭包（闭包不可序列化）。改为数据（payload + 执行器注册表查表）。

## §6 对外协作约定（元宝 / CN 层）

- **CN 类文档（文明注记、元规范）**：定位为独立 **CN 层**——元规范、规范位阶高于宪法、但**强制力为零**。不在 G0–G3 内，不占 G3 席，不走换血制。其"约束 G2/G3"的诉求以"我方认同并自愿受其约束"实现，而非代码强制（代码强制必成假安全机制，参考 `readyz` 先例）。
- **宪法席位紧张时**：走 G3 换血制，AI 无提案权，最高修改门槛。CN 类内容不得悄悄占用 G3 席位。
- **简报配套**：下轮对外简报（v18）须附《基因表达系统设计》全文，并把本约定 §4 模板作为 RFC 提交前置。
