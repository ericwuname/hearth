基因表达系统设计图纸（Gene Expression System）v1.0

状态：顶层设计定稿，待审计窗口审计 → 拆解 → 执行 → 验收
作者：顶层设计窗口 · 2026-07-30
一句话原则：基因 = 会被自动表达的约束。不能被机器表达的，不配叫基因，只配叫文化文档。

§0 设计目标与一句话原则

目标：让规则、SOP、复盘、知识不再以"文字沉积"的方式生长，而是被强制编译进四层表达机制，由机器自动表达——把灵魂侧"靠自觉的栏杆"全部换成身体侧"有牙齿的必然"。

要解决的五个实证病灶（全部来自启元N 的真实反馈）：

  1. 规则太多（53 条全量加载，注意力稀释）
  2. 栏杆没有牙齿（文字规则可轻易越过，靠自觉）
  3. 设计了不执行、不读取（civ 线五个版本未兑现、"连接大脑"靠 CEO 记得说）
  4. 复盘了后面忘了用（心跳#10 教训写成规则二十一，身体又原样栽一遍）
  5. 10G 知识库闲置（只有存，没有召回推送）

§1 四层基因分类（按牙齿硬度，不按内容主题）

层名称牙齿表达器官（身体侧）数量红线
G0结构基因物理不可能违反sandbox(landlock/seccomp)、审批门、CLI 进程隔离无上限，但每条=拓扑级改动，极少新增
G1反射基因代码分支必然执行相位钩子（subconscious gate / nervous query / CostGuard / 交付三门）每条必须挂 wiring 接线断言测试
G2检索基因正确时机出现在眼前experience crate（判例卡 + 情境召回 + 自动注入 prompt）无上限，受 KPI 淘汰
G3叙事基因无牙齿（只做偏置）constitution.md → build_messages 注入≤10 条，永不放宽

判别式（给审计窗口用）

一条规则属于哪层，问一句"违反它的那一刻，会发生什么？"

  • 什么都不发生 → 它现在是栏杆。要么下沉到 G1/G0 给它装牙，要么承认它是 G3 价值偏置（占 10 席之一），要么降为文化文档。
  • 报错/相位拒绝/审批弹窗 → 已有牙，登记它的表达器官和断言测试即可。
入籍铁律：每条基因入籍时必须声明三元组 （层级，表达器官，验证方式）。G1 缺接线断言、G2 缺判例卡格式、G3 超 10 条——任一违反，自动拒绝入籍，退回为文化文档。

§2 消化道设计（本图纸的核心增量）

§1 是静态解剖，§2 是动态代谢。回答的问题：未来的规则/SOP/复盘涌入时，系统靠什么不变成第二个 AGENTS.md V4.0？

2.1 单一入口（Intake Gate）

所有新治理物料——不管叫规则、SOP、复盘、军师令、圆桌决议——只有一个合法入口：提交一张"入籍申请"，走下面的管线。禁止直接往 constitution.md / docs/ 追加规则性文字（追加文化文档除外，但文化文档不得使用"必须/禁止/铁律"字样——用了就说明它想当基因，就得走管线）。

2.2 管线五步（每步有产物，有拒绝出口）

① 提交申请 ──→ ② 分层判定 ──→ ③ 编译 ──→ ④ 表达验证 ──→ ⑤ 挂 KPI
   事故/复盘/     用§1判别式      产出三选一      故意违反一次，   进入退役
   提案原文       定 G0-G3        (见2.3)       牙齿必须咬合     计数循环
      │              │
      │              └─ 判不出层级 → 拒绝入籍 → 归档为文化文档
      └─ 无真实事故/需求支撑 → 拒绝（防冲动立法）

2.3 复盘编译义务（消灭"复盘了忘了用"）

复盘的合法交付物不是文档，是以下三选一（散文结尾的复盘视同没复盘）：

交付物去处成本例
（一）结构基因补丁 / 审批门新增G0高（拓扑改动）—
（二）反射基因新相位钩子 / 断言G1 + wiring 测试中—
（三）判例卡入 experienceG2 情境召回低—
