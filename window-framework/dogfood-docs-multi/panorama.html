⚠️ 经验回路的真相（跨 v17/v18/v19 实证）

经验对弱模型(zhipu) +20pt 有效，对强模型(deepseek, 生产标准脑) 零增量甚至 -5pt 有害。结论 = 经验是可选降级通道（连续失败≥3 才注入），非常驻增强。v17 的"+20pt"是真实弱模型结论，错在外推。
