# EMBER — 使用说明（本机版）

> 一个能**自己动手干活**的小 CLI：会读文件、写文件、跑命令，多轮往复直到把活干完。
> 模型：Agnes `agnes-3.0-flash`（你的会员通道）。**数据只走 Agnes，不落第三方。**

---

## 一、最快的用法

**双击 `用我.bat`** → 出现 `你:` 提示 → 输入问题回车。
- 直接输问题 = 新对话
- 输 `c` 回车 = 接着**上一次**说（它是"记得住的"）
- 关窗口退出

**或者在命令行里用：**

```bat
cd /d C:\Users\87465\Desktop\codex-rust-v1.0-final\ember
ember.bat "你的问题"
```

---

## 二、三种模式

| 想要什么 | 命令 | 说明 |
|---|---|---|
| 问一句 | `ember.bat "解释什么是 PDCA"` | 单轮问答，快（10-20 秒） |
| 干个活 | `ember.bat "在当前目录建 notes.txt，写入今天日期和三条待办"` | **它会自己写文件、读回验证**（30-90 秒） |
| 接着上次 | `ember.bat -c "刚才你创建了什么文件？"` | 加载最近会话，记得上次的活 |
| 看历史 | `ember.bat --list` | 列出历史会话 |

---

## 三、三个可以直接试的例子

1. **最简**：`ember.bat "用三句话说明你是谁"`
2. **动手**：`ember.bat "统计 app.log 里 ERROR 有多少条、按模块分布，写成 report.md"`
3. **记忆**：上一步跑完后 → `ember.bat -c "你刚才的报告放在哪？摘要两句给我"`

（`app.log` 样本已在 `workspace/` 目录里，可以直接用它做实验；建议**在 `workspace/` 里跑**，别在仓库根目录跑，免得它把产物写得到处都是。）

---

## 四、要提前知道的四件事

1. **等 10-90 秒是正常的**——每次都是真实模型调用；复杂的活它要来回好几轮（每轮一次调用）。
2. **它操作"运行时所在的目录"**——相对路径都相对那儿。所以要让它干活，先在目标文件夹里开；
3. **本机命令是 Windows 环境**（Git Bash 工具也在 PATH 里，所以 `ls`/`grep`/`wc` 这类大概率能跑）。它自己会试错调整，不用你管；跑不通它会换写法。
4. **`config.json` 里是你的 key**——别外传、别提交到 git（已被 .gitignore 挡住）。想换 key 或换模型直接编辑这个文件。

## 五、文件都是啥

| 文件 | 作用 |
|---|---|
| `用我.bat` | **双击就能用**（推荐） |
| `ember.bat` | 命令行调用壳 |
| `ember.py` | 主程序（会话 + 工具循环） |
| `tools.py` | 四个工具：`bash` / `read` / `write` / `edit`（`edit` 做精确单处替换，大文件小改动省 token） |
| `config.json` | 模型地址 / 模型名 / 你的 key（**私密**） |
| `workspace/` | 建议的实验目录（含 `app.log` 样本） |
| `README.md` | 本文件 |

## 六、它现在还会什么（能力一览）

- 单轮问答；多轮**工具循环**（读/写/改/跑，自主决定何时用；`edit` 做精确单处替换，大文件小改动省 token）；
- **跨进程记忆**（`-c` 真的记得上次）；
- 每次运行把会话落盘（`.ember/`），随时可续；
- 断链重试（网络抖动等 2/4/8 秒重试）；
- 出错不静默——工具失败会把原因原样返回给它，它会自己纠正重试。
