## 一、这是什么

`AGENTS.md` = hearth-cognition 认知层的**宪法注入件**。锚定仓库根 `constitution.md`（Codex Gene Constitution v1.0，八条全文），通过 Codex CLI 的**原生 AGENTS.md 机制**注入——agent 在本目录下启动时自动加载为最高行为准则。

**为什么宪法注入先行**（顶层批复）：它同时是技能库（件②）与校准观测（件③）的**测试载体**。

## 二、部署方式（标准协议）

```bash
cd cognition-mvp
codex            # Codex CLI 启动时自动读取本目录 AGENTS.md
```

- Codex CLI 原生支持项目级 `AGENTS.md`（官方指令文件机制）——**零适配、零 patch、零专属 API**。
- 移植到其他底座（Goose 等）：等价指令文件机制同样适用；本文件内容底座无关。
